# 증강 16종과 데이터 기반 효과 설계

## 목표

`CNT-005`의 증강 16종 사양을 확정하고, `CNT-006`에서 모든 증강이 실제 전투에 영향을 주도록 구현한다. 공격만 올리는 선택지에 치우치지 않도록 공격 5종, 생존 4종, 이동·획득 4종, 위험 보상 3종으로 구성한다.

밸런스 수치, 카드 설명, 실제 적용 로직의 기준은 한 곳에 둔다. 이후 플레이테스트에서 수치를 조정할 때 증강 정의만 수정하면 카드의 `현재 → 다음` 표시와 런타임 계산이 함께 바뀌어야 한다.

## 범위

- 기존 증강 12종의 사양과 실제 효과를 정리한다.
- 신규 증강 4종을 추가해 전체 풀을 16종으로 만든다.
- 아직 효과가 없어 선택 후보에서 제외된 기존 증강도 실제 효과를 구현한다.
- 상시 효과, 선택 즉시 효과, 체력 조건부 효과, 불이익을 같은 데이터 모델로 표현한다.
- 해금 여부, 최대 레벨, 레벨업 후보 필터링, 카드 변화량 표시를 16종 모두에 적용한다.
- 밸런스 수치를 찾고 수정하기 쉽게 콘텐츠 정의 파일에 모은다.

이번 범위에서는 신규 아이콘 제작, 해금 목표 추가, 도감 화면, 저장 형식 변경, 무기별 고유 증강, 확률 발동 효과를 다루지 않는다. 신규 4종은 우선 기본 해금 풀에 포함하며, 별도 해금 목표는 후속 콘텐츠 작업에서 연결한다. 기존 저장을 불러올 때도 기본 해금 정의를 저장된 해금 집합에 합쳐 신규 4종이 누락되지 않게 한다. 기존에 잠겨 있던 증강을 이 과정에서 임의로 해금하지는 않는다.

## 증강 구성과 초기 수치

백분율 효과는 기본값에 대해 레벨별로 가산한다. 예를 들어 피해 `+12%/레벨`은 3레벨에서 `+36%`다. 불이익도 같은 방식으로 누적하며, 카드에는 이득과 불이익을 모두 표시한다.

| --- | --- | --- | ---: | --- |

`ritual_shortcut`의 필요 경험치 감소는 현재 레벨의 임계값을 소급해 즉시 레벨업시키지 않는다. 선택 이후 새로 얻는 경험치에 적용되는 다음 임계값부터 반영해 중첩 레벨업과 선택 화면 재진입 문제를 피한다.

`last_stand`의 체력 조건은 현재 체력 ÷ 현재 최대 체력이 0.35 이하일 때 참이다. 조건을 벗어나면 효과는 즉시 사라지고, 다시 조건에 들어오면 복구된다. 체력이 없는 상태나 런 종료 후에는 발동하지 않는다.

## 데이터 모델

`AugmentDefinition`은 표시 정보와 함께 다음 정보를 갖는다.

- `category`: 공격, 생존, 이동·획득, 위험 보상 중 하나
- `effects`: 하나 이상의 타입이 지정된 효과 목록
- 각 효과의 `stat`, 레벨당 `value`, 적용 방식, 선택적 조건, 불이익 여부
- `maxLevel`, `startsUnlocked` 등 기존 선택·해금 정보

효과 타입은 구현에 필요한 범위만 제공한다.

- 지속 능력치: 무기 피해, 원소 피해, 공격 속도, 치명타, 공격 크기, 이동 속도, 접촉 피해, 경험치 배율, 획득 반경, 필요 경험치
- 선택 즉시 효과: 최대 체력 증가와 회복, 단순 회복
- 조건: 항상, 체력 35% 이하

효과 정의는 `lib/game/content/augment_definitions.dart`에 모은다. 수치 상수와 표시 이름을 다른 시스템에 복사하지 않는다. 효과 모델을 담는 공용 타입은 콘텐츠 모델 파일에 두되, 실제 계산 책임은 별도 해석기에 둔다.

## 효과 계산과 데이터 흐름

`AugmentEffectResolver`는 현재 증강 레벨과 플레이어 상태를 입력받아 불변 `AugmentModifiers`를 반환한다. 게임은 이 결과만 사용해 피해, 속도, 크기, 획득 범위, 경험치, 받는 피해와 레벨 요구량을 계산한다.

흐름은 다음과 같다.

1. 레벨업 시스템이 해금 상태와 최대 레벨을 확인한다.
2. 정의의 효과 데이터를 사용해 현재 레벨과 다음 레벨의 카드 문구를 만든다.
3. 플레이어가 선택하면 증강 레벨을 올린다.
4. 선택 즉시 효과만 한 번 적용한다.
5. 지속 효과는 매번 해석한 수정치를 전투·이동·획득 계산에 사용한다.
6. 체력 조건부 효과는 현재 체력 비율이 변할 때 자연스럽게 켜지고 꺼진다.

기존 `PixelSurvivorGame`과 `LevelUpSystem`의 증강 ID별 `switch` 및 지원 ID 목록은 제거한다. 정의에 유효한 효과가 있는 증강만 자동으로 후보가 되므로, 새 증강을 추가할 때 여러 파일의 허용 목록을 함께 고칠 필요가 없어야 한다.

## 카드 표시

카드는 정의의 효과 목록으로부터 문구를 생성한다. 누적형 효과는 현재 합계와 다음 합계를 `현재 → 다음`으로 보여 준다. 즉시 회복은 선택 시 발생하는 고정량으로 표시한다. 조건부 효과는 `체력 35% 이하` 조건을 앞에 붙인다.

위험 보상 증강은 같은 카드에 이득과 불이익을 함께 표시한다. 예를 들어 강력한 일격 1레벨 선택 전에는 `무기 피해 +0% → +18% · 공격 속도 +0% → -8%`로 보여 주어 불이익이 숨겨지지 않게 한다.

카드 문구를 위한 별도 수치표나 ID별 문자열 분기는 두지 않는다. 정의에 없는 효과나 지원하지 않는 효과 타입은 개발 중 즉시 드러나도록 명시적인 오류를 내며, 빈 설명의 카드는 후보에 넣지 않는다.

## 안전 규칙

- 치명타 확률은 0~100%로 제한한다.
- 공격 속도 배율과 이동 속도 배율은 0.1 미만으로 내려가지 않게 한다.
- 받는 접촉 피해 배율은 0 이상으로 제한한다.
- 경험치 획득 반경은 기본 반경의 25% 미만으로 내려가지 않게 한다.
- 필요 경험치 감소는 80%를 넘지 않게 제한한다.
- 회복은 현재 최대 체력을 넘지 않으며, 사망한 플레이어에게 즉시 효과를 적용하지 않는다.
- 정의 ID는 유일해야 하고 모든 정의는 하나 이상의 효과를 가져야 한다.

현재 초기 수치에서는 제한값에 닿지 않지만, 향후 밸런스 수정 실수로 게임 진행이 멈추는 것을 방지하기 위해 계산 경계에서 강제한다.

## 테스트 전략

사용자가 요청한 최소 테스트 원칙에 맞춰 중복 조합을 전부 나열하지 않고, 데이터와 공통 해석기를 집중 검증한다.

- 콘텐츠 테스트: 정확히 16종, ID 유일성, 분류별 5·4·4·3 분포, 최대 레벨, 모든 효과 데이터 유효성
- 해석기 단위 테스트: 상시 이득, 복합 이득·불이익, 화염 피해, 경험치·필요 경험치, 체력 35% 조건의 경계값
- 카드 테스트: 누적 `현재 → 다음`, 즉시 회복, 조건 문구, 불이익 동시 표시
- 게임 통합 테스트: 증강 선택 후 즉시 회복·최대 체력, 접촉 피해 감소·증가, 조건부 최후의 저항, 경험치 배율과 다음 레벨 임계값 반영
- 회귀 테스트: 최대 레벨과 잠긴 증강 제외, 런 재시작 시 임시 증강 초기화

구현 중에는 변경한 시스템의 표적 테스트를 우선 실행하고, 완료 시 전체 Flutter 테스트를 한 번 실행한다. 현재 세션에서는 Windows 테스터 안정성을 위해 `TEMP`와 `TMP`를 `C:\\codex-temp`로 지정한다.

## 완료 조건

- 콘텐츠 정의에 증강이 정확히 16종 존재하고 분류 분포가 5·4·4·3이다.
- 16종 모두 선택 가능하며 카드에 실제 효과와 일치하는 한국어 변화량이 표시된다.
- 상시, 즉시, 조건부, 불이익 효과가 실제 게임 계산에 반영된다.
- 밸런스 수치가 증강 정의 한 곳에만 존재하며 런타임과 카드가 이를 공유한다.
- 기존 무기·증강 선택, 저장, 해금, 런 초기화 동작을 깨뜨리지 않는다.
- `CNT-005`와 `CNT-006`이 검증 근거와 함께 완료 처리된다.
