# 조선 전투 마스터리 수직 슬라이스 설계

## 목표

5분형 조선 민속 판타지 생존 액션의 첫 전투 마스터리 수직 슬라이스를 만든다. 환도와 부적은 레벨 1부터 5까지 행동이 누적되고 레벨 6에서 공격 구조와 화면 연출이 바뀌는 마스터 무기로 진화한다. 봉마참 시너지, 네 가지 적 행동, 높은 후반 적 밀도, 공통 전투 피드백과 플레이테스트 로그를 함께 연결해 “강한 무기로 많은 몬스터를 쓸어버리는 감각”을 실제 플레이로 검증한다.

이번 범위는 콘텐츠 수를 채우는 작업이 아니다. 화포 계통, 나머지 두 시너지, 전체 캐릭터·몬스터 이미지 제작과 10~12종 기본 무기 로스터 완성은 후속 수직 슬라이스로 남긴다.

## 조사 결과

### 무기와 성장

현재 무기는 환도, 각궁, 부적, 벽력진천뢰, 장승 결계, 신기전, 서리 호리병, 풍뢰 부채의 8종이다. 공격 형태는 근접 부채꼴, 직선 투사체, 다중 직접 타격, 지연 폭발, 추종 오라, 밀집 방향 산탄, 감속 장판, 양방향 넉백으로 구분되어 있다.

그러나 모든 무기는 5레벨 상한이고 `WeaponLevelDefinition`의 피해, 쿨다운, 범위, 공격 수, 관통, 연쇄, 넉백 중심으로 성장한다. 환도 5레벨은 동시에 생성되는 2개 부채꼴, 부적 5레벨은 타깃 수 증가이므로 최종 완성의 구조적 변화가 없다. `WeaponSystem` 한 클래스가 무기별 발사 메서드와 쿨다운을 모두 소유한다.

### 증강과 시너지

증강은 16종이며 공격, 생존, 이동·획득, 위험·보상 범주로 나뉜다. 현재 효과는 피해, 공속, 치명타, 크기, 이동, 체력 등 수치 수정뿐이다. 두 무기의 상태와 타격 규칙을 연결하는 시너지 시스템은 없다.

### 해금과 저장

기본 저장은 `startsUnlocked`인 환도와 각궁만 연다. 해금 목표와 저장 데이터에는 나머지 무기 해금 상태가 보존되지만 실제 런 생성자는 저장된 무기 목록을 받지 않고 시작 무기와 `startsUnlocked` 목록만 사용한다. 개발 플레이테스트 전용 정책을 런에 주입하면 기존 저장과 해금 목표를 변경하지 않고 모든 구현 무기를 열 수 있다.

### 적과 웨이브

일반 적 8종, 고유 엘리트 3종, 보스가 있으며 추격, 무리 분리, 돌진, 급강하, 찌르기, 사망 장판, 강화 오라, 연속 돌진, 충격파, 비명 행동이 존재한다. 위험 행동은 공통 상태 머신과 경고 표시를 사용한다. 원거리 유지·투사체 행동과 방향 방어 판정은 없다.

웨이브 데이터의 후반 활성 상한은 스테이지에 따라 92~102명이지만 기존 고정 시드 성능 기록의 실제 최대 적은 34명이었다. 마스터 무기의 대량 처치 장면을 검증하려면 생성 압력과 조합을 조정하고 실제 활성 수와 프레임 시간을 다시 측정해야 한다.

### 아트, 피드백과 성능

중앙 에셋 카탈로그, 스프라이트 아틀라스 계약, 안전 로더와 코드 도형 폴백이 있다. 현재 작업 트리에는 충돌 크기를 유지하면서 플레이어 108px, 일반 적 54px, 엘리트 81px, 보스 126px로 확대하는 미커밋 변경이 있다. 이 변경은 보존하고 새 스타일의 크기·화면 밀도 검증 기반으로 사용한다.

치명타, 피해 숫자, 사망 효과, 제한된 화면 흔들림과 컴포넌트 상한은 존재한다. 마스터 전용 사운드 등급, 히트스톱, 연속 처치, 시너지 안내와 효과 중첩 제한은 추가해야 한다. 기존 런 로그는 무기별 피해·처치와 선택 기록을 지원하지만 마스터, 시너지, 행동 유형, 적 수, FPS와 재도전 지표는 지원하지 않는다.

## 선택한 구조

완전 범용 효과 그래프를 도입하거나 기존 `WeaponSystem`에 모든 상태를 계속 추가하지 않는다. 환도와 부적은 각각 독립 실행기가 연속 동작과 지속 상태를 관리하고, 공통 공격 명세가 판정·이펙트·피드백의 단일 원천이 되는 혼합 구조를 사용한다. 기존 나머지 6종은 현재 실행 경로를 유지한다.

### 공통 공격 계약

`AttackSpec`은 다음 정보를 가진다.

- 무기 또는 시너지 ID와 공격 단계
- 부채꼴, 원, 직선 중 판정 형상
- 방향, 범위, 각도, 반경
- 준비, 발동, 잔상 시간
- 피해, 넉백, 감속
- 관통, 폭발, 마스터, 시너지 등 공격 특성
- 궤적 색상, 효과 강도와 사운드 등급

실행 시점에는 변경 불가능한 `AttackInstance`를 생성한다. 판정과 렌더링은 같은 인스턴스의 방향·형상·타이밍을 사용한다. 게임 루프는 실행기가 만든 공격과 상태 변화를 기존 피해·사망·통계 경계에 전달한다.

무기별 실행기는 다음 책임만 가진다.

- 현재 레벨에 맞는 행동 순서 결정
- 쿨다운과 시간차 공격 큐 관리
- 무기 고유 상태인 부적 표식과 결계 관리
- `AttackInstance`와 전투 피드백 요청 생성

피해 적용, 방어 판정, 사망 기록, 시너지 피해 집계와 효과 상한은 게임의 공통 전투 경계에서 처리한다.

## 6단계 성장

환도와 부적의 `maxLevel`은 6이다. 레벨 1~5는 성장 과정이고 레벨 6은 별도 `master` 단계다. 기존 나머지 무기의 5레벨 상한과 저장 ID는 유지한다.

### 환도 계통

| 레벨 | 행동 변화 |
| --- | --- |
| 1 | 가장 가까운 적 방향으로 짧은 부채꼴 베기. 사거리 안 적이 없으면 마지막 이동·공격 방향을 사용한다. |
| 2 | 피해와 범위가 증가하고 쿨다운이 소폭 감소한다. |
| 3 | 첫 베기 뒤 짧은 시간차를 두고 반대 각도의 두 번째 베기를 실행한다. |
| 4 | 두 번째 베기 뒤 같은 방향으로 짧은 검기를 발사한다. |
| 5 | 베기 각도와 범위가 커지고 환도 처치가 남은 쿨다운을 줄인다. 환급량에는 공격당 상한을 둔다. |
| 6 | 최근접 방향의 강한 첫 베기, 좌우 반원, 원형 검격, 대형 마무리 검기를 순서대로 실행하는 다단 환도 폭풍으로 교체한다. |

마스터 환도는 한 프레임의 원형 피해가 아니다. 각 단계의 방향, 범위와 발동 시간이 화면에서 읽혀야 한다. 일반 적은 대량 처치할 수 있지만 엘리트와 보스는 전체 연타를 맞아도 즉시 삭제되지 않게 피해 계수를 분리한다.

### 부적 계통

| 레벨 | 행동 변화 |
| --- | --- |
| 1 | 가까운 적 또는 작은 적 무리에 부적을 투척해 즉시 타격한다. |
| 2 | 피해와 투척 빈도가 증가한다. |
| 3 | 부적이 적에게 부착되고 짧은 예고 뒤 폭발한다. |
| 4 | 폭발이 주변의 아직 표식 없는 적에게 제한 횟수만큼 전이된다. |
| 5 | 폭발 위치에 짧게 유지되는 소형 감속 결계를 생성한다. |
| 6 | 적 밀집 지점 여러 곳에 대형 오방색 결계를 만들고 내부 적을 감속하며 주기적으로 연속 폭발한다. |

동시 부착 표식 수, 전이 깊이, 결계 수와 결계당 타격 수에는 명시적 상한을 둔다. 이미 제거 중이거나 죽은 대상의 표식은 정리하고, 유효 대상이 없으면 새 표식이나 결계를 만들지 않는다.

## 봉마참 시너지

환도와 부적을 모두 보유하면 봉마참 규칙이 자동 활성화된다.

1. 환도 타격이 부적 표식이 없는 적에게 봉마 표식을 부여한다.
2. 표식이 있는 적을 환도로 다시 베면 표식을 소비하고 폭발한다.
3. 폭발은 주변의 아직 표식 없는 적에게 제한 수만큼 봉마 표식을 전이한다.
4. 전이된 표식도 후속 환도 타격으로 폭발할 수 있지만 한 공격 연쇄의 깊이와 총 대상 수를 제한한다.

봉마참 피해는 `sealing_slash` ID로 따로 집계한다. 최초 발동 때만 짧은 안내를 표시하고 이후에는 제한 주기의 이름 표시, 황금빛 검격과 오방색 봉인 파편, 전용 사운드 등급으로 일반 공격과 구분한다. 시너지 안내는 적 경고선과 플레이어 상태 UI를 가리지 않는다.

## 플레이테스트 개방 정책

`PlaytestContentPolicy`를 런 생성자에 주입한다.

- 개발 플레이테스트 모드는 현재 실제 구현된 기본 무기 8종을 모두 선택 후보로 연다.
- 일반 모드는 기존 저장과 해금 목표를 유지한다.
- 캐릭터 시작 무기는 항상 레벨 1로 지급한다.
- 정책은 생성자 주입을 기본으로 하고 `dart-define`은 앱 진입점의 기본값만 선택한다.
- 단위 테스트는 전역 환경 변수가 아니라 명시적 정책 인스턴스를 사용한다.

현재 구현된 기본 무기가 8종뿐이므로 이번 범위에서 복제 공격의 미완성 무기 2~4종을 추가하지 않는다. 10~12종 기본 로스터 목표는 환도·부적 마스터의 재미가 검증된 뒤 화포 계통과 고유 공격 무기를 추가하는 후속 단계에서 달성한다.

## 적 행동 수직 슬라이스

### 무리형

기존 역병 쥐떼를 사용한다. 낮은 체력, 빠른 접근과 같은 종류끼리의 분리 이동을 유지하고 후반 웨이브 비중과 동시 수를 높인다. 범위·연쇄 공격의 주요 처치 대상이다.

### 돌진형

기존 원혼을 사용한다. 준비 시간을 모바일에서 읽을 수 있게 늘리고 몸을 움츠리는 도형 변화와 고정 방향 예고선을 함께 표시한다. 경고가 시작된 뒤에는 방향을 다시 추적하지 않는다.

### 원거리형

임시 삿갓 망령 정의와 원거리 행동 프로필을 추가한다. 선호 거리 바깥에서는 접근하고, 안쪽에서는 후퇴하며, 적정 거리에서는 멈춰 예고 후 혼령탄을 발사한다. 혼령탄은 배경과 마스터 이펙트 모두에서 구분되는 위험색 외곽선을 사용하고 화면 밖에서 제거된다.

### 방어형

기존 도깨비에 방향 방어를 추가한다. 플레이어를 향해 방어 방향을 갱신하고 정면에서 들어오는 일반 근접·투사체 피해를 줄인다. 측후면, 관통, 폭발과 시너지 공격에는 방어 효율이 낮다. 방어 성공은 별도 작은 효과를 표시하되 피해가 0이 되지는 않는다.

위험 행동은 `tracking → warning → active → recovery → cooldown` 흐름을 사용한다. 적 투사체도 공통 생성 상한과 제거 규칙을 통과한다.

## 후반 밀도와 밸런스

- 0~60초: 작은 무리 중심으로 기본 공격을 읽힌다.
- 60~180초: 돌진형과 원거리형을 순차 혼합한다.
- 180~240초: 무리, 돌진, 원거리와 방어형을 함께 배치한다.
- 240~270초: 마스터 무기의 대량 처치 장면을 위한 최고 밀도를 만든다.
- 보스 등장 이후: 일반 적 수는 낮추되 특수 행동 조합은 유지한다.

활성 적 상한은 고정 시드 성능 로그를 보며 단계적으로 높인다. 프레임당 생성 요청 8개 상한, 경험치 보석 병합, 피해 숫자·전투 효과·투사체 상한을 유지한다. 난도는 체력 일괄 증가가 아니라 수, 행동 조합, 접근 방향과 엘리트 비중 순서로 조정한다.

## 전투 피드백

공통 피드백 조정기는 히트스톱, 화면 흔들림, 연속 처치 표시와 동시 효과 강도를 제한한다.

- 일반 강타는 약 20ms의 작은 히트스톱을 요청한다.
- 마스터 핵심 타격은 약 35ms를 요청하되 연속 요청을 누적하지 않고 상한값으로 합친다.
- 화면 흔들림은 기존 접근성 설정을 존중하고 마스터 시작과 마무리에서만 강화한다.
- 환도 마스터는 청백색 대형 검기, 금빛 마무리와 굵은 잔상을 사용한다.
- 부적 마스터는 오방색 외곽, 한지색 내부와 순차 폭발을 사용한다.
- 마스터와 봉마참은 별도 오디오 큐를 가진다. 첫 구현은 승인된 기존 음원을 겹치거나 피치·재생 순서를 달리하는 임시 레이어를 사용하고 교체 가능한 에셋 계약을 유지한다.
- 짧은 시간창의 연속 처치 수만 표시하며 중요한 적 경고보다 낮은 시각 우선순위를 사용한다.
- 흰색 전체 화면 플래시와 지속 흔들림은 사용하지 않는다.

## 새로운 아트 방향

기존 작은 호러 픽셀 아트 확장을 중단하고 새 가이드에 다음을 고정한다.

- 조선 민속 판타지의 3~4등신 비율
- 큰 머리, 손과 무기로 읽히는 실루엣
- 굵고 깨끗한 외곽선과 2~3단 셀 셰이딩
- 밝은 본체색과 강한 공격색의 대비
- 작은 모바일 화면에서도 보이는 눈, 입과 감정 표현
- 환도 검객의 갓·망건·철릭·큰 환도
- 무당의 넓은 소매·부채·부적·방울
- 포수의 조총·화약 주머니·과장된 갓
- 도깨비 사냥꾼의 붉은 두루마기·방망이 또는 쇠사슬
- 꼬마 도깨비, 항아리 귀신, 장승 귀신, 삿갓 망령, 불도깨비, 달걀귀신, 저승사자 하수인, 호랑이 요괴, 역병귀와 타락한 무관의 고유 실루엣 명세
- 일본 사무라이 갑주·월대, 중국식 장포·무협 검객 문법을 피하고 철릭, 두루마기, 갓, 망건, 조총, 장승과 오방색을 우선하는 복식 체크리스트

최종 이미지는 이번 범위에서 대량 제작하지 않는다. 현재 확대 에셋과 코드 도형 폴백을 사용해 108/54/81/126px 시각 크기와 전투 밀도를 먼저 검증한다. 충돌 크기, 이동 수치와 카메라 확대는 유지한다.

## 텔레메트리

런 텔레메트리를 스키마 2로 확장하되 기존 스키마 1 로그를 기본값으로 읽을 수 있게 한다. 저장 진행 데이터의 스키마는 변경하지 않는다.

수집 항목은 다음과 같다.

- 무기별 선택지 제시 횟수와 선택 횟수
- 무기별 피해 합계와 피해 비중 계산용 전체 피해
- 무기 레벨 변화 시각
- 최초 마스터 달성 시각
- 마스터 발동 후 10초간 처치 수
- 봉마참 최초 발동 시각과 피해 합계
- 적 행동 유형별 플레이어에게 준 피해
- 적 행동 유형별 사망 원인 ID
- 화면 내 적 수의 프레임 평균과 최대
- 180초 이후 평균 FPS와 최저 FPS
- 런 종료 시 마스터 달성 여부
- 동일 설치 플레이테스트 기록에서 두 번째 이상 런인지 여부

마스터 달성·미달성 런의 승률과 무기·시너지 피해 비중은 여러 런을 읽는 집계 리포터가 계산한다. `PixelSurvivorGame.update`는 전투 계산에 사용하는 제한된 `dt`와 별도로 원래 프레임 `dt`를 성능 샘플에 사용한다. 로그는 재미의 증거가 아니라 수동 플레이 평가를 보조하는 자료로 취급한다.

## 오류와 경계 처리

- 죽거나 제거 중인 적은 새 공격과 표식 대상에서 제외한다.
- 표식 대상이 제거되면 실행기가 다음 틱에서 상태를 정리한다.
- 연쇄, 결계, 시간차 공격과 적 투사체는 각각 동시 수 상한을 가진다.
- 공격 방향이 0벡터면 최근 유효 방향, 없으면 오른쪽 단위 벡터를 사용한다.
- 비정상적인 음수 시간, 범위, 피해와 유효하지 않은 레벨 정의는 콘텐츠 검증에서 실패한다.
- 텔레메트리 저장 실패는 런 종료, 보상 저장과 화면 전환을 막지 않는다.
- 접근성에서 화면 흔들림이 꺼져 있으면 마스터와 시너지도 흔들지 않는다.
- 기존 미커밋 렌더링·환도 조준 변경과 저장 데이터는 삭제하거나 되돌리지 않는다.

## 테스트 전략

모든 행동 변경은 실패 테스트를 먼저 작성하고 예상 이유로 실패하는 것을 확인한 뒤 최소 구현을 추가한다.

### 단위 및 컴포넌트 테스트

- 환도와 부적이 정확히 6레벨이며 다른 무기의 상한이 유지된다.
- 레벨별로 새 공격 단계가 정확한 시간과 형상으로 발생한다.
- 마스터 이전과 이후의 공격 패턴·범위·효과 등급이 다르다.
- 환도 처치 쿨다운 환급과 상한이 동작한다.
- 부적 부착, 지연 폭발, 전이, 결계와 상태 정리가 동작한다.
- 봉마참은 표식 부여, 재타격 폭발, 제한 전이와 별도 피해 ID를 사용한다.
- 판정과 렌더링 요청이 같은 `AttackInstance`를 참조한다.
- 원거리형 거리 유지, 경고, 투사체와 제거 규칙이 동작한다.
- 방어형 정면 감소, 측후면·관통·폭발·시너지 약점이 동작한다.
- 히트스톱, 흔들림과 안내 중첩 상한이 접근성 설정을 존중한다.
- 스키마 1 로그를 읽고 스키마 2를 왕복 직렬화한다.

### 통합 및 시뮬레이션 테스트

- 플레이테스트 모드에서는 구현된 8종이 모두 후보이고 일반 모드는 기존 해금을 유지한다.
- 5분 고정 시드에서 웨이브별 행동 조합, 생성 상한, 평균·최대 적 수를 기록한다.
- 마스터 후 10초 처치와 봉마참 피해가 런 결과에 포함된다.
- 보스는 정확히 한 번 등장하고 마스터 무기에 즉시 삭제되지 않는다.
- 컴포넌트와 지속 상태 소유자가 상한을 넘거나 런 종료 후 남지 않는다.

### 완료 검증

한글 경로에서 Flutter 분석 서버와 셰이더 컴파일러 문제가 있으므로 Flutter SDK와 저장소를 임시 ASCII `subst` 드라이브에 연결해 다음을 새로 실행한다.

1. `flutter analyze`
2. 전체 `flutter test`
3. `flutter build web`
4. `flutter build apk --debug`
5. 고정 시드 5분 시뮬레이션과 텔레메트리 집계

임시 드라이브는 검증 후 제거한다. 기존 작업 트리의 사용자 변경은 검증을 위해 삭제하거나 초기화하지 않는다.

## 실제 플레이 체크리스트

- 플레이어, 일반 적, 엘리트와 보스가 모바일 화면에서 실루엣으로 구분되는가?
- 환도 레벨 1, 3, 4, 5와 6이 서로 다른 공격으로 보이는가?
- 부적의 부착, 폭발, 전이, 소형 결계와 마스터 결계가 읽히는가?
- 마스터 발동 순간 무기가 잠시 화면의 주인공처럼 보이는가?
- 봉마참 이름, 색상과 소리가 일반 공격과 구분되는가?
- 적 공격 경고가 마스터·시너지 효과 위에서도 보이는가?
- 원거리형 때문에 접근 경로를 바꾸고 돌진형 때문에 회피하게 되는가?
- 방어형의 정면과 측후면 대응 차이를 시각적으로 이해할 수 있는가?
- 240~270초에 일반 적을 대량 처치하면서 엘리트와 보스는 남는가?
- 마스터가 없어도 회피와 운영으로 생존할 수 있는가?
- 화면 흔들림과 히트스톱이 과하지 않고 끈 설정이 존중되는가?
- 두 번째 런을 실제로 다시 시작하고 싶었는가?
