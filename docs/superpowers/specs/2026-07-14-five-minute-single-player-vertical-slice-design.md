# 조선시대 서바이벌 5분 1인 전투 설계

## 목표

현재 구현된 이동, 자동 공격, 경험치 획득, 레벨업, 피해, 사망, 저장 흐름을 바탕으로 첫 스테이지를 시작부터 보스 처치까지 완주 가능한 5분짜리 세로 완성본으로 만든다.

이 단계의 성공 기준은 그래픽 없이도 전투의 성장감, 무기별 차이, 적 조합의 압박, 보스 공략의 재미를 판단할 수 있는 것이다. 첫 플레이의 목표 승률은 약 70%로 잡는다.

게임은 1인 전용이다. 두 번째 플레이어, 로컬 협동, 온라인 협동, 공유 경험치, 부활 협동 기능은 구현하지 않는다. 런타임에서도 활성 플레이어는 정확히 한 명만 허용한다.

## 첫 스테이지

첫 스테이지는 역병과 원혼이 퍼진 조선의 버려진 마을이다. 기본 캐릭터는 순라군이며 시작 무기는 환도 베기다.

| 시간 | 진행 |
| --- | --- |
| 0:00~1:00 | 역병쥐 위주로 이동, 자동 공격, 경험치 획득을 익힌다. |
| 1:00~2:00 | 산적이 합류하고 적이 여러 방향에서 접근한다. |
| 2:00~3:00 | 원혼이 합류해 간헐적인 돌진으로 회피를 요구한다. |
| 3:00~4:00 | 도깨비와 정예 몬스터가 등장해 범위 공격과 화력 성장을 시험한다. |
| 4:00~4:30 | 물량이 크게 증가하는 최종 파상공세가 진행된다. |
| 4:30 | 보스 타락한 관군 대장이 정확히 한 번 등장한다. |
| 5:00 전후 | 보스 처치 시 승리한다. |
| 5:30 | 보스가 광폭화해 장기 도주를 방지한다. |

보스가 살아 있는 동안 일반 적은 제한된 수만 보충한다. 플레이어 사망 시 즉시 패배하며, 보스 처치 시 남은 일반 적과 관계없이 즉시 승리한다.

## 웨이브 디렉터

현재의 고정 3초 간격 단일 스폰을 시간 구간 기반 웨이브 디렉터로 교체한다. 각 구간은 출현 가능한 적, 초당 생성량, 무리 크기, 정예 확률, 동시 적 상한을 데이터로 가진다.

웨이브 디렉터는 다음 책임만 가진다.

- 현재 시간에 맞는 웨이브 구간 선택
- 프레임 시간과 무관한 누적 스폰 예산 계산
- 화면 가장자리의 유효 위치 선택
- 동시 적 상한 준수
- 보스 단일 생성 보장

난수 시드를 주입할 수 있게 만들어 테스트에서 동일한 웨이브를 재현한다. 낮은 프레임률에서도 한 프레임에 과도한 적이 생성되지 않도록 프레임당 생성 상한을 둔다.

## 무기

첫 스테이지에서는 네 무기를 실제 선택하고 강화할 수 있다.

### 환도 베기

플레이어가 바라보는 목표 방향으로 부채꼴 근접 공격을 한다. 적을 약하게 밀쳐내며 레벨에 따라 피해량, 범위, 공격 속도, 검기 수가 증가한다. 5레벨에서는 좌우를 연속으로 베어 근접 방어력이 크게 오른다.

### 각궁 사격

가장 가까운 적에게 빠른 화살을 발사한다. 레벨에 따라 피해량, 투사체 수, 관통 수, 공격 속도가 증가한다. 5레벨에서는 첫 대상 뒤의 적에게 추가 피해를 준다.

### 부적 투척

가장 가까운 적을 맞힌 뒤 주변 적에게 연쇄되는 부적을 던진다. 원혼 계열에게 추가 피해를 준다. 레벨에 따라 연쇄 횟수, 탐색 범위, 피해량, 공격 속도가 증가한다.

### 벽력진천뢰

적이 밀집한 위치에 경고 원을 표시하고 짧은 지연 후 폭발한다. 레벨에 따라 폭발 범위, 피해량, 동시 폭발 수, 재사용 시간이 개선된다. 강한 대신 즉시 피해가 아니므로 다른 무기와 다른 위치 선정이 필요하다.

무기마다 레벨별 수치를 데이터로 정의한다. 단순한 공통 공식만 사용하지 않고 공격 개수, 범위, 관통, 연쇄, 지연 시간처럼 행동이 실제로 달라지게 한다. 무기 진화는 이 범위에 포함하지 않는다.

## 증강과 레벨업

첫 세로 완성본에서는 실제 효과가 완전히 적용되는 증강 여덟 종만 레벨업 후보로 사용한다.

- 무예 단련: 모든 무기 피해 증가
- 빠른 발놀림: 이동 속도 증가
- 빠른 장전: 공격 재사용 시간 감소
- 내공 호흡: 최대 체력 증가 및 증가량만큼 현재 체력 회복
- 매의 눈: 치명타 확률 증가
- 약초 주머니: 일정 레벨마다 즉시 체력 회복
- 장승의 가호: 경험치 획득 범위 증가
- 화약 조제: 폭발 범위와 투사체 크기 증가

한 판에서 8~12회 레벨업하도록 경험치 곡선을 조정한다. 선택지는 세 장이며 무기와 증강이 가능한 한 섞여 나오게 한다. 각 카드에는 현재 레벨, 다음 레벨, 실제 변화량을 한글로 표시한다. 최대 레벨 항목과 아직 영구 해금되지 않은 항목은 후보에서 제외한다.

## 적

- 역병쥐: 체력이 낮고 빠르며 작은 무리로 생성된다.
- 산적: 기준이 되는 추적형 적이다.
- 원혼: 일정 주기로 플레이어 방향으로 짧게 돌진한다.
- 도깨비: 느리고 단단하며 밀치기 저항을 가진다.
- 정예: 일반 적 중 하나를 강화한 형태로 크기, 테두리, 체력과 경험치가 다르다.

그래픽을 붙이기 전에도 크기, 색, 이동 패턴, 외곽선으로 종류를 구분한다. 접촉 피해는 짧은 무적 시간 또는 적별 공격 간격을 적용해 여러 적이 겹쳤을 때 체력이 한 프레임에 사라지는 상황을 막는다.

## 보스

타락한 관군 대장은 상태 기반 패턴 제어기를 사용한다.

1. 플레이어 방향을 예고한 뒤 직선 돌진한다.
2. 부채꼴 검기 경고를 표시하고 공격해 안전한 측면 이동을 요구한다.
3. 체력 40% 이하에서 원혼을 소환하고 연속 돌진을 사용한다.
4. 등장 후 60초가 지나면 공격 속도와 이동 속도가 증가하는 광폭화 상태가 된다.

공격 전에는 플레이어가 반응할 수 있는 경고 영역을 반드시 표시한다. 보스는 한 런에 한 번만 생성되며 체력바는 화면 상단에 고정한다.

## 전투 피드백

도트 그래픽과 음향이 없어도 손맛을 평가할 수 있도록 다음 효과를 도형 기반으로 구현한다.

- 피격 시 적의 짧은 점멸
- 근접 공격과 폭발의 넉백
- 제한된 수의 피해 숫자
- 폭발 및 보스 공격 경고 영역
- 처치 시 짧은 축소 또는 소멸 효과
- 강한 폭발과 보스 피격의 약한 화면 흔들림

동시 적, 투사체, 피해 숫자, 시각 효과에는 각각 상한을 둔다. 오래 플레이해도 제거된 컴포넌트가 누적되지 않아야 한다.

## 화면 흐름

게임 HUD에는 시간, 체력, 레벨, 경험치, 처치 수, 보유 무기 목록을 표시한다. 보스 등장 중에는 상단에 이름과 체력바를 추가한다.

레벨업 화면은 게임을 완전히 일시 정지한다. 선택 카드에는 한글 이름과 구체적인 효과를 표시한다. 선택 후 중복 입력으로 두 번 적용되지 않아야 한다.

결과 화면은 승리와 패배를 명확히 구분하고 다음 정보를 표시한다.

- 생존 시간
- 처치 수
- 도달 레벨
- 보유 무기와 최종 레벨
- 보스 처치 여부
- 새로 해금된 항목

재도전은 같은 스테이지를 새 상태로 시작하며 이전 런의 적, 타이머, 무기 재사용 시간, 임시 증강 효과가 남지 않아야 한다.

## 코드 구조

기존 `PixelSurvivorGame`에 집중된 책임을 다음 단위로 분리한다.

- `WaveDirector`: 시간 구간, 스폰 예산, 정예, 보스 생성 관리
- `CombatSystem`: 피해 판정, 치명타, 넉백, 접촉 피해 간격 관리
- `WeaponController`: 무기별 실행기와 레벨 데이터 조합
- `BossController`: 보스 상태와 패턴 전환 관리
- `RunStateController`: 진행 중, 레벨업 일시 정지, 승리, 패배 상태 관리

각 시스템은 화면 컴포넌트를 직접 탐색하기보다 필요한 대상 목록과 이벤트를 명시적으로 전달받는다. 게임 화면은 시스템을 조율하고 UI에 읽기 전용 상태를 제공한다.

## 오류 및 경계 조건

- 화면 크기가 확정되기 전에는 적과 플레이어를 생성하지 않는다.
- 유효한 스폰 위치를 찾지 못하면 해당 프레임의 생성을 건너뛴다.
- 레벨업 후보가 없으면 게임을 일시 정지하지 않는다.
- 승리와 패배 콜백은 한 런에서 정확히 한 번만 호출한다.
- 보스 처치와 플레이어 사망이 같은 프레임에 발생하면 보스 처치를 먼저 판정해 승리로 처리한다.
- 큰 프레임 시간은 내부 업데이트 단위로 제한해 이동, 피해, 스폰 폭주를 방지한다.

## 검증

자동 테스트는 다음을 포함한다.

- 시간 구간별 적 종류, 스폰 예산, 동시 적 상한
- 4분 30초 보스 단일 생성과 광폭화
- 네 무기의 레벨별 행동과 피해 판정
- 여덟 증강의 실제 수치 적용
- 접촉 피해 간격과 사망 판정
- 보스 처치 우선순위와 승리 콜백 단일 호출
- 재도전 시 런 상태 초기화
- 고정 난수 시드 기반 5분 전투 시뮬레이션

완료 전 `dart analyze`, `flutter test`, `flutter build web`, Android 디버그 빌드를 실행한다. 브라우저에서 시작, 이동, 레벨업, 보스 등장, 승리, 재도전까지 직접 확인하고 수동 QA 문서를 갱신한다.

## 완료 기준

- 5분 전후에 끝나는 완전한 1인 플레이 한 판이 존재한다.
- 보스는 정확히 한 번 등장하고 처치 시 승리한다.
- 네 무기의 공격 방식이 그래픽 없이도 구분된다.
- 일반적인 한 판에서 8~12회 레벨업한다.
- 첫 플레이 목표 승률은 약 70%다.
- 적과 효과가 누적되어 성능이 지속적으로 저하되지 않는다.
- 자동 테스트와 웹 및 Android 빌드가 통과한다.
- 구현 단위별 커밋을 GitHub 원격 브랜치에 푸시한다.
