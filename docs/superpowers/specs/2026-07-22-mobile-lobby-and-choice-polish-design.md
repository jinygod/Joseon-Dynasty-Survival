# 모바일 로비·전투 HUD·선택 카드 개선 설계

## 목표

기존 고화질 조선 캐릭터와 전투 구조를 유지하면서 모바일 화면에서 어색한 방향 전환, 체력 인지 부족, 단조로운 로비, 잘리는 증강 설명을 함께 해결한다. 참고 이미지에서는 밝고 강한 색상 대비와 정보 계층만 참고하며 캐릭터, 아이콘, 배경, UI 구조를 복제하지 않는다.

## 선택한 접근

기존 Flutter·Flame 구조와 현재 에셋을 활용하는 코드 중심 개선안을 적용한다. 신규 일러스트를 대량 제작하지 않고 레이아웃, 도형, 그라데이션, 외곽선과 현재 대표 캐릭터 아트를 조합한다. 세로 모바일을 우선하고 넓은 화면에서는 기존 정보 밀도를 유지하는 적응형 레이아웃을 사용한다.

## 캐릭터 방향 전환

- 현재 `+1`과 `-1` 사이를 보간하는 X축 스케일 애니메이션을 제거한다. 중간값이 0에 가까워지며 캐릭터가 판처럼 납작해지는 현상의 직접 원인이다.
- 좌우 입력이나 공격 방향이 바뀌면 스프라이트를 즉시 수평 반전한다.
- 걷기 바운스, 작은 기울기, 공격 펄스는 유지하되 수평 반전과 별도로 계산한다.
- 위아래 이동만 입력될 때는 마지막 좌우 방향을 유지한다.
- 충돌 크기, 공격 방향, 실제 피해 판정은 변경하지 않는다.

## 캐릭터 하단 체력바

- 플레이어 컴포넌트가 자신의 현재 체력 비율에서 직접 그리는 월드 체력바를 추가한다.
- 체력바는 캐릭터 발밑 중앙에 배치하고 기본 크기는 약 `30 x 5` 논리 픽셀로 한다.
- 검은 반투명 외곽선과 어두운 트랙을 사용하고, 안전 구간은 청록색, 낮은 체력은 황색, 위험 구간은 적색으로 구분한다.
- 체력바는 캐릭터의 좌우 반전·회전·바운스 변환을 받지 않아 항상 수평으로 보인다.
- 기존 상단 HUD 체력 정보는 접근성과 정확한 수치 확인을 위해 유지한다.

## 플로팅 조이스틱

- 입력이 없을 때 조이스틱 안내 위치를 화면 하단 중앙에 둔다.
- 전투 화면의 조작 가능 영역을 누르면 고정된 좌측 하단 원점 대신 최초 접촉 지점을 해당 드래그의 중심점으로 사용한다.
- 손가락 이동량은 최대 반경에서 제한하고, 손가락을 떼면 입력을 0으로 되돌린 뒤 안내 위치를 하단 중앙으로 복귀시킨다.
- 일시정지, 레벨업 선택, 결과 화면과 다른 상호작용 UI가 열린 동안에는 전투 입력을 받지 않는다.
- SafeArea와 상단 HUD를 침범하지 않으며 멀티터치에서는 시작 포인터 하나만 조이스틱이 소유한다.

## 로비

- 세로 모바일에서는 상단 자원 바, 중앙 출진 무대, 하단 메뉴의 세 영역으로 재배치한다.
- 배경은 밝은 한지색과 주황·황금색 강조색을 사용하고, 도트 또는 구름 무늬를 낮은 대비로 넣어 캐주얼한 밀도를 만든다.
- 중앙 무대에는 선택한 맵 이름, 최고 기록, 현재 캐릭터, 기존 고화질 캐릭터 이미지, 큰 `출진` 버튼을 표시한다.
- 무대는 조선 관아의 처마·기둥·마당을 단순 도형과 현재 로비 텍스처로 표현한다.
- 캐릭터·맵·도감·기록·설정 기능과 기존 Key는 유지한다. 작은 화면에서는 하단 메뉴, 넓은 화면에서는 좌우 보조 메뉴로 배치한다.
- 프리미엄 구매 기능을 강조하거나 새로운 상점을 추가하지 않는다.

## 레벨업·증강 선택 카드

- 화면 상단에 `성장 선택` 제목 띠를 두고 선택 화면 전체를 어둡게 처리해 전투와 분리한다.
- 카드에는 종류, 이름, 현재→다음 레벨, 효과 설명, 단계 표시를 명확한 순서로 배치한다.
- 노란색은 무기 또는 일반 강화, 녹색은 신규 증강·특수 선택의 강조에 사용한다. 본문은 짙은 남색으로 통일한다.
- 세로 모바일에서는 세 카드를 위아래로 배치한 넓은 행 카드로 보여 이름과 효과 설명을 생략하지 않는다.
- 넓은 화면에서는 세 개의 세로 카드를 나란히 표시한다.
- 텍스트는 한국어 줄바꿈을 허용하고 `FittedBox`로 과도하게 축소하지 않는다. 효과 영역은 유연하게 확장하며 카드 전체가 SafeArea 안에서 스크롤 가능하다.
- 설명이 예외적으로 길어도 잘리지 않도록 `SingleChildScrollView`와 최소 높이 기반 레이아웃을 사용한다.

## 구성 경계와 데이터 흐름

- `PlayerComponent`: 방향 전환과 월드 체력바만 담당한다.
- `LobbyScreen`: 저장 상태에서 선택 캐릭터·맵·재화를 읽어 적응형 로비 위젯에 전달한다.
- `LevelUpOverlay`: 기존 `LevelUpChoice` 데이터를 변경하지 않고 표시 방식만 바꾼다.
- `VirtualJoystick`: 포인터 시작 위치와 현재 위치에서 입력 벡터를 계산하고, `GameScreen`은 빈 전투 영역의 포인터 이벤트만 전달한다.
- 선택 콜백, 저장, 전투 일시정지, 증강 효과 적용 로직은 기존 흐름을 그대로 사용한다.
- 이미지 로딩 실패 시 로비 무대는 조선색 도형 실루엣과 캐릭터 자리표시자로 안전하게 대체한다.

## 검증

- 방향 전환 직후 수평 스케일이 `0` 근처를 지나지 않는 컴포넌트 테스트를 추가한다.
- 체력바 크기·위치·위험 색상 선택 규칙을 테스트 가능한 값으로 고정한다.
- `390 x 844`에서 로비 핵심 버튼과 메뉴가 화면 안에 있고 스크롤로 접근 가능한지 위젯 테스트한다.
- 같은 크기에서 레벨업 선택 3개의 이름과 전체 효과 설명이 모두 렌더링되는지 검사한다.
- 화면의 서로 다른 두 지점에서 드래그를 시작해도 각각의 시작 지점이 중심이 되고, 해제 직후 입력이 0으로 돌아가는지 검사한다.
- 가로 화면 및 텍스트 배율 증가 시 오버플로가 없는지 기존 접근성 테스트와 함께 확인한다.
- 관련 골든을 갱신하고 시각 검사 후 전체 `flutter test`, `flutter analyze`, 웹 릴리스, Android 디버그 빌드를 실행한다.

## 완료 기준

- 좌우 전환 시 판처럼 납작해지는 프레임이 없다.
- 플레이어 발밑 체력바가 공격 이펙트와 구분되고 체력 변화에 즉시 반응한다.
- 로비에서 선택 맵·캐릭터·출진 행동이 첫 화면의 중심으로 보인다.
- 세로 모바일 증강 선택에서 이름, 레벨 변화, 효과 설명이 잘리지 않는다.
- 조이스틱이 하단 중앙에 안내되고 어느 빈 전투 지점에서도 새 중심으로 조작할 수 있다.
- 기존 저장 데이터, 선택 콜백, 해금 정책과 전투 판정이 유지된다.
