# 조선 로비 타이포그래피·내비게이션 개선 설계

## 목표

현재 로비의 기본 고딕체와 평평한 Material 버튼 인상을 제거한다. 특정 상용 게임의 화면을 복제하지 않고, 현대 모바일 게임의 강한 정보 계층과 누르기 쉬운 입체 버튼 구조를 조선 민속 판타지 색상·문양으로 재해석한다.

## 선택한 접근

폰트만 교체하는 최소안은 버튼의 도구 화면 같은 인상을 해결하지 못하고, 신규 일러스트 중심 안은 이번 범위에 비해 제작 비용이 크다. 따라서 앱에 공개 라이선스 한글 폰트를 내장하고 기존 Flutter 로비를 세 영역으로 재구성하는 코드 중심안을 적용한다.

## 타이포그래피

- `Song Myung`을 앱 로고, 선택 무대 이름, 주요 장식 제목에 사용한다. 획의 붓맛은 큰 글자에서만 사용한다.
- `Gowun Batang Regular/Bold`를 버튼, 자원 수치, 설명과 작은 정보에 사용해 명조 분위기와 모바일 가독성을 함께 확보한다.
- 폰트 파일과 SIL Open Font License 1.1 원문을 앱에 함께 포함한다.
- 앱 전역 `ThemeData`의 기본 글꼴은 `Gowun Batang`으로 지정하되, 게임 HUD 숫자처럼 폭과 즉시성이 중요한 기존 전투 표현은 필요하면 명시 스타일을 유지한다.
- 굵기만으로 계층을 만들지 않고 크기, 색상, 짧은 그림자, 자간을 함께 사용한다. 긴 본문에 과한 외곽선이나 붓글씨를 사용하지 않는다.

## 로비 구조

### 상단 지휘 패널

- 앱 제목은 한지 명패처럼 보이는 영역에 배치하고 `Song Myung`으로 표시한다.
- 수련 단계와 재화는 한 줄의 어두운 목재·금속 패널 안에서 서로 다른 메달형 칸으로 나눈다.
- 설정은 작은 기본 아이콘 버튼 대신 톱니 문양이 든 입체 원형 버튼으로 만든다.
- 실제 재화 값, 구매 진입 조건과 기존 Key는 변경하지 않는다.

### 중앙 출진 무대

- 현재 관아 도형 배경을 유지하되 처마, 기둥, 무대 바닥, 구름·광륜을 더 명확한 레이어로 보강한다.
- `오늘의 출진`, 무대 이름, 최고 기록, 캐릭터 이름의 순서를 명확히 나눈다.
- 캐릭터는 중앙 광륜과 받침 위에 크게 표시한다.
- 출진 버튼은 금색 상판, 어두운 하부 깊이, 붉은 테두리, 상단 하이라이트를 가진 큰 게임 버튼으로 교체한다. 비활성 상태도 형태는 유지하면서 채도와 명도를 낮춘다.

### 하단 메뉴 도크

- 흩어진 네 개의 `FilledButton.tonal`을 화면 폭을 채우는 고정형 목재 도크로 교체한다.
- 지도, 인물, 도감, 기록은 각자 금속 테두리와 색상 구분이 있는 아이콘 메달, 큰 라벨, 눌림 깊이를 가진다.
- 버튼 하나의 터치 영역은 최소 72 논리 픽셀 높이와 64 논리 픽셀 너비를 확보한다.
- 기능, 내비게이션 콜백, 접근성 라벨과 기존 `lobby-stage`, `lobby-character`, `lobby-compendium`, `lobby-records` Key는 유지한다.

## 반응형·접근성

- 390×844 세로 화면에서는 상단 패널, 확장 가능한 중앙 카드, 고정 하단 도크가 첫 화면 안에 들어온다.
- 화면 높이가 작거나 텍스트 배율이 크면 중앙 영역만 스크롤하고 상단 핵심 정보와 하단 메뉴는 접근 가능하게 유지한다.
- 넓은 화면에서는 중앙 무대 폭을 제한하고 메뉴 도크를 하단 중앙에 배치해 버튼 외형을 동일하게 유지한다.
- 색상만으로 버튼 기능을 구분하지 않으며 아이콘, 라벨, 시맨틱 버튼 역할을 함께 제공한다.

## 구성 경계

- `JoseonUiTheme`: 앱 글꼴 이름, 색상, 전역 텍스트·버튼 기본값을 제공한다.
- `LobbyScreen`: 저장 상태와 콜백을 기존처럼 읽고 적응형 영역 배치만 담당한다.
- `LobbyTopCommandBar`: 제목, 수련 단계, 재화, 설정을 표시한다.
- `LobbyBattleStage`: 무대·캐릭터·기록·출진 행동을 표시한다.
- `LobbyNavigationDock`과 `LobbyNavigationButton`: 네 목적지의 동일한 시각·상호작용 계약을 담당한다.
- 새 UI 컴포넌트는 표시 상태만 가지며 저장·구매·전투 시작 로직을 소유하지 않는다.

## 테스트

- 테마가 내장 폰트 가족을 사용하고 폰트 파일 및 라이선스가 `pubspec.yaml`에 등록됐는지 검사한다.
- 390×844에서 제목, 자원, 출진 버튼, 네 메뉴가 모두 표시되고 오버플로가 없는지 검사한다.
- 하단 메뉴가 최소 터치 크기, 입체 레이어 Key, 아이콘과 라벨을 갖는지 검사한다.
- 기존 지도·인물·도감·기록·설정·출진 내비게이션 테스트를 유지한다.
- 실제 내장 폰트를 사용하는 세로 로비 골든을 추가하고 원본 해상도로 시각 검사한다.
- 전체 `flutter test`, `flutter analyze`, 웹 릴리스 빌드, Android 디버그 빌드를 통과시킨다.

## 완료 조건

- 첫 화면에서 기본 고딕체가 로비의 주된 인상으로 보이지 않는다.
- 하단 메뉴와 출진 버튼이 설정 화면 버튼이 아니라 모바일 게임의 주요 조작 요소처럼 보인다.
- 조선 복식 캐릭터, 관아 무대, 한지·목재·금색 UI가 하나의 시각 언어로 연결된다.
- 기존 기능, 저장 데이터, 구매 진입 조건과 내비게이션 Key가 유지된다.
- 휴대폰 외부 링크에서 새 로비를 바로 확인할 수 있다.
