# 2개 스테이지 로스터 설계

## 목표

5분 런의 기본 규칙은 유지하면서 `달빛 폐관아`와 `역병 장터`가 적 구성, 생성 압력, 정예 등장 시점, 화면 분위기에서 분명히 구분되도록 한다.

## 스테이지 구성

### 달빛 폐관아

- 역할: 첫 플레이에 적합한 표준 난이도.
- 주요 적: 떠도는 망자, 산적, 원혼과 괴이 계열을 시간에 따라 고르게 섞는다.
- 압력: 현재 생성 속도와 동시 적 상한을 기준선으로 유지한다.
- 정예: 1분 이후 낮은 확률로 시작해 4분 이후 점진적으로 증가한다.
- 시각 메타데이터: 남색 배경, 달빛 아이콘, `표준` 위험도.

### 역병 장터

- 역할: 독 장판과 빠른 진입 적에 대응하는 상급 난이도.
- 주요 적: 굶주린 쥐떼, 역병 까마귀, 부패한 약초꾼을 일찍 배치하고 중후반에 원혼과 도깨비를 섞는다.
- 압력: 달빛 폐관아보다 생성 속도와 동시 적 상한을 약 10% 높인다. 프레임당 생성 상한 8은 유지한다.
- 정예: 1분 구간부터 등장하며 달빛 폐관아보다 각 구간 확률이 높다.
- 시각 메타데이터: 탁한 녹갈색 배경, 위험 경고 아이콘, `위험` 난이도.

## 데이터 구조

- `StageDefinition`에 선택 화면용 아이콘 종류, 배경색, 위험도 문구를 추가한다.
- 스테이지 ID별 `List<WaveDefinition>`을 반환하는 중앙 조회 함수를 둔다.
- 기존 `waveDefinitions` 이름은 달빛 폐관아의 호환 별칭으로 유지해 기존 밸런스 테스트와 저장 데이터를 깨지 않는다.
- `WaveDirector`는 웨이브 목록과 보스 출현 시점을 주입받는다.
- `PixelSurvivorGame`은 `stageId`를 받아 해당 스테이지 웨이브로 `WaveDirector`를 생성한다.
- `GameScreen`은 선택된 `stageId`를 게임 생성자에 전달한다.

## 선택 화면

- 가로 화면에서 두 스테이지 카드를 나란히 표시한다.
- 선택된 카드의 이름, 설명, 생존 목표, 보스 출현 시점, 위험도를 오른쪽 정보 영역에 표시한다.
- 카드 선택 후 기존 확인 버튼으로 저장하며 알 수 없는 저장 ID는 첫 스테이지로 복구한다.

## 검증

- 두 스테이지 ID, 이름, 위험도, 웨이브 목록이 서로 다르다.
- 모든 웨이브의 시간 구간이 0초부터 연속이고 적 등급과 가중치가 유효하다.
- 역병 장터는 0초, 120초, 240초 기준 생성 속도와 동시 적 상한이 달빛 폐관아보다 높다.
- 동일한 고정 시드에서 각 스테이지는 자기 적 풀만 사용하고 보스를 270초에 한 번 요청한다.
- 선택 화면에서 역병 장터를 선택해 반환할 수 있고, 선택한 ID가 `GameScreen`과 `PixelSurvivorGame`까지 전달된다.
- 16:9, 18:9, 19.5:9, 4:3 안전 영역 테스트를 유지한다.

## 제외 범위

신규 배경 이미지, 타일 충돌, 지형 장애물, 스테이지 전용 보스, 신규 음원은 후속 아트와 보스 작업에서 다룬다.
