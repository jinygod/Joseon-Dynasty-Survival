# 일반 적 8종·고유 엘리트 3종 설계

## 목표

출시용 두 스테이지가 공유할 일반 적 8종과 고유 엘리트 3종의 역할, 데이터 계약, 행동 규칙을 확정한다. 현재 달빛 폐관아에는 일부만 배치하고 나머지는 두 번째 스테이지의 핵심 적으로 남겨, 한 화면에 모든 적을 몰아넣지 않고 스테이지별 전투 정체성을 만든다.

이 설계는 `CNT-007`을 완료하고 후속 `CNT-008`의 구현 경계를 제공한다. 정확한 스테이지별 웨이브와 등장 시점은 `CNT-009`에서 결정한다.

## 승인된 방향

- 일반 적 8종과 엘리트 3종은 모두 고유 ID, 한국어 이름, 역할, 행동 데이터를 가진다.
- 엘리트는 일반 적의 체력·피해·크기만 키운 변형이 아니라 전용 적 정의로 만든다.
- 11종은 출시용 두 스테이지의 공용 로스터이며, 현재 스테이지에는 일부만 등장한다.
- 1차 구현에서는 적 투사체를 사용하지 않는다.
- 위험한 행동은 돌진, 짧은 찌르기, 사망 독장판, 강화 오라, 충격파, 비명 파동처럼 범위와 발동 시점이 보이는 패턴으로 제한한다.
- 세부 수치와 웨이브 가중치는 데이터로 유지해 플레이테스트 후 ID나 상태 머신을 바꾸지 않고 조정한다.

## 검토한 접근법

### 1. 고유 로스터 방식 — 선택

일반 적과 엘리트가 각각 독립된 정의와 상태 머신을 가진다. 구현량은 가장 많지만 작은 화면에서도 처치 우선순위와 위협을 구분하기 쉽고, 엘리트 처치 및 혼옥 드롭의 의미가 분명하다.

### 2. 강화 변형 방식

일반 적에게 체력, 피해, 속도 배율과 색상만 적용한다. 기존 구조를 가장 적게 바꾸지만 엘리트가 단순 수치 증가처럼 보이고 고유 보상과 전투 기억점이 약하다.

### 3. 혼합 방식

고유 엘리트와 강화 변형을 함께 사용한다. 장기 확장에는 유연하지만 1.0에서 엘리트 판정과 에셋·보상 규칙이 두 갈래가 되어 불필요하게 복잡하다.

세 적은 `EnemyRank.elite`이며 기존 런 통계의 `isElite`, 엘리트 처치 엽전 보상, 혼옥 드롭 판정을 그대로 사용한다. 일반 적을 임의로 확대하는 기존 `isElite` 생성 방식은 호환용으로 사용하지 않고, 엘리트 확률이 발동하면 고유 엘리트 풀에서 하나를 선택한다.

## 스테이지 분배 원칙

현재 달빛 폐관아의 1차 풀은 다음과 같다.

- 핵심 일반 적: 역병 쥐떼, 산적, 도깨비, 원혼
- 후반 일반 적 후보: 창 든 산적, 무덤 불씨
- 엘리트 후보: 깨진 장승령, 한 맺힌 처녀귀

두 번째 스테이지는 역병 까마귀, 부패한 약초꾼, 검은 삿갓 자객을 핵심 차별점으로 사용하고 공용 적 일부를 섞는다. 이 목록은 소유권과 역할만 정하며, 실제 등장 시간, 가중치, 엘리트 확률은 `CNT-009`의 스테이지 설계에서 고정한다.

## 데이터 구조

`EnemyDefinition`은 다음 정보를 가진다.

- 안정적인 `EnemyId`
- 한국어 표시 이름
- `EnemyFaction`: `plague`, `bandit`, `spirit`, `anomaly`
- `EnemyRank`: `normal`, `elite`, `boss`
- 체력, 이동 속도, 접촉 피해, 경험치
- 행동 프로필 ID

행동 수치는 `EnemyBehaviorProfile`로 분리한다.

- `EnemyBehaviorKind`: 기존 추격·무리·돌진·탱커와 신규 급강하·찌르기·사망 장판·강화 오라·연속 돌진·충격파·비명
- 준비 시간, 활성 시간, 재사용 대기시간
- 이동 배율, 범위, 효과 배율
- 동시에 유지할 수 있는 환경 효과 수

행동 프로필은 적 정의와 별도 중앙 목록에 두며 적 컴포넌트는 프로필 ID로 조회한다. 이 경계는 플레이테스트 수치 조정이 적 기본 능력치나 웨이브 데이터를 불필요하게 변경하지 않게 한다.

`WaveDefinition`은 기존 `enemyWeights`와 별도로 `eliteWeights`를 가진다. `eliteChance`가 실패하면 일반 풀에서, 성공하면 고유 엘리트 풀에서 선택한다. 엘리트 풀이 비어 있으면 일반 적을 강화하지 않고 일반 풀에서 정상 생성해 잘못된 데이터가 게임을 중단시키지 않게 한다.

## 행동과 전투 흐름

위험 행동은 공통 상태 순서를 따른다.

1. 추적 또는 대기
2. 준비 경고
3. 방향 또는 범위 고정
4. 발동
5. 회복 시간
6. 재사용 대기

경고가 시작된 뒤 플레이어 위치를 무제한 추적하지 않는다. 돌진과 찌르기는 발동 직전에 방향을 고정하고, 충격파와 비명은 경고 원 안에서만 피해를 준다. 감속 오라와 이동 강화 오라는 같은 출처 유형끼리 중첩하지 않고 가장 강한 값 하나만 적용한다.

부패한 약초꾼의 독장판은 적 사망 이벤트에서 생성되며 처치당 한 개만 만든다. 독장판은 최대 동시 수를 넘으면 가장 오래된 것부터 제거한다. 환경 효과는 적 활성 수와 별도지만 전역 상한을 가져 장시간 전투에서도 컴포넌트가 무제한 증가하지 않게 한다.

## 생성과 성능 안전

- 프레임당 생성 요청 8개 상한을 유지한다.
- 엘리트도 활성 적 상한 한 자리를 사용한다.
- 향후 소환 행동이 추가되더라도 `WaveDirector`와 동일한 활성 용량 확인을 통과해야 한다.
- 오라 대상 탐색은 매 프레임 전체 목록을 중복 순회하지 않고 기존 근접 적 공급자 또는 제한 주기 쿼리를 사용한다.
- 독장판, 경고 범위, 충격파 효과는 각각 전역 동시 수 상한을 가진다.
- 보스는 `EnemyRank.boss`로 유지하며 엘리트 풀에 들어가지 않는다.

## 에셋과 가독성

- 신규 최종 스프라이트가 준비되기 전에는 기존 `SafeAssetLoader`와 도형 폴백을 사용한다.
- 일반 적은 24px 또는 32px, 고유 엘리트는 40px 또는 48px 원본 규격을 목표로 한다.
- 엘리트는 색상만이 아니라 실루엣 크기, 테두리, 경고 모양으로 구분한다.
- 공격 경고는 피해 효과보다 먼저 보이고, 플레이어·경험치 보석·혼옥보다 낮은 시각 우선순위를 사용한다.
- 투사체 공격과 화면 밖 즉발 피해는 이번 범위에서 제외한다.

## 오류 처리와 호환성

- 알 수 없는 행동 프로필 ID는 중립 추격 행동으로 대체하고 개발 빌드에서 한 번 기록한다.
- 비정상적인 음수 시간·범위·배율은 콘텐츠 정의 검증에서 거절한다.
- 엘리트 풀의 ID가 `EnemyRank.elite`가 아니거나 일반 풀에 보스가 들어가면 테스트와 검증기가 실패한다.
- 기존 저장은 적 ID를 보존하지 않으므로 저장 스키마를 올리지 않는다.
- 기존 텔레메트리의 전체 처치, 엘리트 처치, 마지막 피해 원인은 신규 ID를 그대로 수용한다.
- 신규 이미지 로드 실패는 게임 로직과 보상을 중단하지 않는다.

## 검증

- 정의 검증: 일반 적 정확히 8종, 고유 엘리트 정확히 3종, 보스 1종 이상, 모든 ID와 표시 이름 고유
- 참조 검증: 모든 적의 행동 프로필 존재, 모든 웨이브 ID 존재, 일반·엘리트·보스 풀 등급 일치
- 상태 머신 검증: 준비, 방향 고정, 발동, 회복, 재사용 대기 전환과 경계 시간
- 효과 검증: 독장판 1회 생성·만료·상한, 오라 비중첩, 충격파와 비명 범위 밖 무피해
- 보상 검증: 고유 엘리트 처치가 `eliteKills`, 엽전 보상, 혼옥 드롭 후보에 한 번만 반영
- 시뮬레이션: 고정 시드 20개에서 프레임당 생성 8개 이하, 활성 적 상한 위반 0회, 보스 요청 정확히 1회
- 회귀 검증: 현재 5분 기준 프로필 9~12 레벨업 유지, 기존 8개 무기와 16개 증강 테스트 유지
- 릴리스 게이트: 포맷, 정적 분석, 전체 Flutter 테스트, 웹 빌드, Android 디버그 APK

## 완료 기준

- 코드와 문서에서 일반 적 8종과 고유 엘리트 3종의 역할이 모호하지 않다.
- 모든 위험 행동이 피할 수 있는 경고와 고정된 발동 범위를 가진다.
- 엘리트가 일반 적 확대판이 아니라 전투 방식과 처치 우선순위로 구분된다.
- 두 스테이지가 같은 11종을 공유하되 서로 다른 핵심 적 조합을 만들 수 있다.
- 신규 행동과 효과가 생성·컴포넌트 상한을 우회하지 않는다.
- 기존 저장, 런 통계, 재화 보상, 혼옥 드롭과 호환된다.

## 범위 밖

- 두 번째 스테이지의 이름, 배경, 환경 기믹, 초 단위 웨이브
- 신규 보스 2종
- 적 원거리 투사체와 탄막
- 최종 적·엘리트 스프라이트 제작과 승인
- 적 도감 화면과 개별 처치 통계 UI
- 상태 이상 저항과 원소별 약점 체계
