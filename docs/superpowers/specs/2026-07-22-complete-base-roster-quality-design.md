# 기본 콘텐츠 완성·품질 통일 설계

## 목표

현재 게임은 신규 128px 아틀라스와 구형 32~64px 이미지, 스프라이트가 없는 적의 사각형 폴백이 같은 전투에 섞인다. 릴리스 빌드에서는 기본 무기·캐릭터·스테이지도 해금에 막혀 실제 플레이가 환도와 각궁 위주로 좁아진다.

이번 작업은 기본 콘텐츠를 먼저 완성하고 모두 개방한다. 완료 후에는 선택 가능한 캐릭터, 실제 웨이브에 등장하는 적, 선택 가능한 무기, 선택 가능한 스테이지 중 임시 사각형이나 구형 저해상도 아트에 의존하는 항목이 없어야 한다. 해금은 이후 별도 작업에서 특수 진화, 도전 변형, 외형 보상에만 사용한다.

## 확정 원칙

- 기존 콘텐츠 ID와 저장 데이터를 삭제하거나 변경하지 않는다.
- 모든 기본 캐릭터 3종, 기본 무기 12종, 기본 스테이지 2종은 새 게임과 기존 저장 모두에서 항상 사용 가능하다.
- 시작 무기는 캐릭터별로 고정하지만 나머지 기본 무기는 모두 레벨업 후보가 된다.
- 한 런에서 장착 가능한 무기는 최대 6종이다. 전체 12종 개방과 한 런 장착 수는 구분한다.
- 캐릭터·적은 모두 128×128 프레임, 4×4, 512×512 RGBA 아틀라스를 사용한다.
- 실제 웨이브나 선택 화면에서 구형 정적 이미지와 사각형 폴백을 사용하지 않는다.
- 특정 상용 게임의 캐릭터·UI·이펙트를 복제하지 않는다.

## 확인된 원인

- `GameScreen`의 릴리스 빌드는 `PLAYTEST_UNLOCK_ALL_BASE_WEAPONS` 기본값이 `false`여서 시작 개방 무기만 노출한다.
- `SaveState.defaults()`는 신참 포졸, 환도·각궁, 달빛 폐관아만 기본 개방한다.
- 선택된 신참 포졸과 산길 사냥꾼은 신규 아틀라스를 사용하지 않고 기존 정적 이미지를 공유한다.
- 실제 웨이브의 산적·역병 까마귀·창 든 산적·부패한 약초꾼·무덤 불씨·엘리트 3종은 신규 아틀라스가 없다.
- 스프라이트가 없는 적은 `EnemyComponent.render()`의 사각형 폴백으로 표시된다. 모바일 사진의 큰 주황색 사각형이 이 경로다.
- 두 스테이지가 같은 프로그램식 한지 배경을 공유해 장소 정체성이 약하다.

## 아트 품질 하한선

### 캐릭터

- 3등신을 기본으로 하고 얼굴, 손, 주무기를 크게 그린다.
- 128px 원본에서 굵고 깨끗한 외곽선과 2~3단 셀 셰이딩을 사용한다.
- 런타임 표시 크기는 기본 64px로 한다. 충돌 크기는 기존 24px를 유지한다.
- 다운스케일에는 중간 품질 필터를 사용해 128px 원본의 선이 모바일 웹에서 깨지지 않게 한다.
- 이동 0~3, 공격 4~7, 피격 8~9, 사망 10~15 프레임 계약을 사용한다.
- 정지는 이동 애니메이션 전체가 아니라 안정된 정지 프레임을 사용한다.

캐릭터 3종:

1. `rookie_constable`: 둥근 얼굴의 신참 포졸, 청색·적색 포졸복, 작은 전립, 큰 환도.
2. `exorcist_dosa`: 넓은 소매의 귀여운 퇴마 도사, 부적과 방울, 황금·주홍 포인트.
3. `mountain_hunter`: 과장된 갓과 짧은 저고리, 큰 각궁과 화살통을 든 산길 사냥꾼.

### 적

- 일반 적 표시 크기는 역할에 따라 36~48px, 엘리트 56~64px, 보스 88px를 기준으로 한다.
- 기존 충돌 크기와 행동 판정은 바꾸지 않는다.
- 13개 적 정의 모두에 128px 16프레임 아틀라스를 연결한다.
- 이미 완성된 역병 쥐떼, 원혼, 삿갓 망령, 도깨비도 동일 품질 게이트를 다시 통과한다.
- 새로 제작할 9종은 산적, 역병 까마귀, 창 든 산적, 부패한 약초꾼, 무덤 불씨, 검은 삿갓 자객, 깨진 장승령, 한 맺힌 처녀귀, 타락한 관군 대장이다.
- 각 적의 공격 행은 실제 행동 예고와 일치해야 한다.
- production 웨이브가 참조하는 적 ID에 아틀라스가 없으면 콘텐츠 무결성 테스트가 실패한다.

### 스테이지

두 스테이지는 1024×1024 고해상도 반복 지면과 저비용 전경 장식을 사용한다. 충돌은 추가하지 않는다.

- 달빛 폐관아: 따뜻한 한지 흙바닥, 흐린 돌길, 기와 파편, 관아 담장 그림자, 홍살문 색 포인트.
- 역병 장터: 탁한 옥색 흙바닥, 장터 천막 그림자, 약재 꾸러미, 항아리, 밧줄, 독기 얼룩.

HUD와 공격 경고가 묻히지 않도록 지면 대비를 낮추고, 플레이어 주변 중앙 45%에는 큰 장식을 두지 않는다.

## 기본 무기 12종

모든 무기는 레벨 1~6을 가지며 6레벨은 단순 수치 상승이 아닌 마스터 진화다.

1. 환도 베기 — 근접 부채꼴에서 다단 환도 폭풍으로 진화.
2. 각궁 사격 — 정밀 단일 사격에서 마스터 `관월추성`으로 진화. 가장 강한 적을 조준한 큰 관통 화살 뒤에 두 발의 추격 화살이 다른 적 또는 같은 강적에게 이어진다. 폭발은 사용하지 않아 조총·신기전과 구분한다.
3. 부적 투척 — 부착·전이·결계에서 오방색 연속 폭발로 진화.
4. 벽력진천뢰 — 지연 폭발에서 넓은 연쇄 화약 폭발로 진화.
5. 장승 결계 — 플레이어 중심 방어 영역에서 이동하는 장승 수호진으로 진화.
6. 신기전 일제사격 — 밀집 방향 다발 사격에서 화면 여러 열을 덮는 화살비로 진화.
7. 서리 호리병 — 감속 지대에서 파열하며 번지는 빙결 호수로 진화.
8. 풍뢰 부채 — 양방향 부채꼴에서 회전하는 풍뢰 태풍으로 진화.
9. 조총·화포 — 느린 직선 관통탄에서 화면을 가르는 대형 화포와 후방 폭발로 진화.
10. 무당 방울 — 주위를 도는 방울과 음파에서 여러 겹의 진혼 파동으로 진화.
11. 도깨비 쇠사슬 — 회전 타격과 끌어모으기에서 전방위를 휘감는 쇠사슬 폭풍으로 진화.
12. 매 부름 — 가장 밀집한 적 무리를 가로지르는 매에서 여러 차례 왕복 급강하하는 수호매로 진화.

각궁은 기존 5레벨에서 6레벨로 확장하며, 레벨업 UI·무기 정의·시뮬레이터·콘텐츠 무결성 테스트가 모두 최대 레벨 6을 공유해야 한다.

## 무기 성장과 선택 규칙

- 레벨 1은 기본 공격, 레벨 2는 기본 성능 강화, 레벨 3은 새 행동, 레벨 4는 약점 보완, 레벨 5는 형태 확대, 레벨 6은 마스터 진화다.
- 12종 모두 레벨 3과 6에서 공격 규칙 또는 궤적이 달라진다.
- 공격 이펙트는 피해 판정과 같은 공격 데이터에서 방향·반경·타이밍을 읽는다.
- 한 런의 무기 슬롯은 6개다.
- 슬롯이 남아 있을 때는 신규 무기와 보유 무기 강화를 함께 제시한다.
- 슬롯이 가득 차면 보유 무기 강화만 제시한다.
- 마스터를 달성할 수 있도록 보유 무기 강화가 최소 한 칸 포함되도록 선택 가중치를 둔다.
- 캐릭터 시작 무기는 첫 레벨로 자동 장착되고 슬롯 하나를 사용한다.

## 기본 개방 정책과 저장 마이그레이션

- `BaseContentPolicy`가 기본 캐릭터·기본 무기·기본 스테이지 ID 집합을 단일 관리한다.
- 새 게임 기본값은 캐릭터 3종, 무기 12종, 스테이지 2종을 모두 개방한다.
- 기존 저장을 읽을 때 기존 집합에 기본 ID를 합친다. 재화, 훈련, 상점, 기록, 완료 목표, 보상 수령 기록은 그대로 보존한다.
- 기존 선택 캐릭터와 스테이지가 유효하면 유지한다.
- 기존 해금 목표 ID와 완료 기록은 삭제하지 않는다. 기본 콘텐츠 해금 보상은 더 이상 접근을 막지 않는 레거시 업적으로 취급한다.
- 선택 화면에는 기본 콘텐츠를 잠금 없이 표시하고 `기본 제공`으로 표기한다.
- 이후 해금 시스템은 별도 계획에서 특수 진화, 도전 변형, 외형 보상만 대상으로 한다.

## 구현 순서

1. 기본 개방 정책과 기존 저장 합집합 마이그레이션.
2. 캐릭터 3종 아틀라스 통일과 모바일 렌더 필터.
3. production 적 13종 아틀라스 완성 및 사각형 폴백 차단.
4. 스테이지 2종 고해상도 배경과 장소별 장식.
5. 기존 무기 8종을 전부 6레벨 마스터 구조로 보강. 각궁 `관월추성` 포함.
6. 신규 무기 4종을 레벨 1~6까지 구현.
7. 6슬롯 선택 규칙과 레벨업 가중치.
8. 모바일 초반·후반 골든, 5분 성능, 전체 빌드 검증.
9. 외부 폰 플레이 후 아트 승인 상태 전환.

## 품질 게이트

- 선택 가능한 캐릭터 3종 모두 512×512 RGBA 아틀라스를 가진다.
- production 웨이브의 적 13종 모두 512×512 RGBA 아틀라스를 가진다.
- 실제 플레이 캡처에 사각형 적 폴백이 0개다.
- 스테이지 2종이 실루엣과 색만으로 구분된다.
- 무기 12종 모두 레벨 1~6 정의와 실행 경로가 있다.
- 각 무기는 다른 공격 규칙을 사용하고 레벨 6 전후 화면이 명확히 다르다.
- 새 게임과 기존 저장 모두 기본 캐릭터 3종, 무기 12종, 스테이지 2종에 접근할 수 있다.
- 기존 저장의 재화·기록·완료 목표가 보존된다.
- 390×844 모바일 골든에서 플레이어 얼굴·무기·적 역할이 구분된다.
- 후반 평균 적 수 30~55, 전역 상한 96, 피해 숫자 상한 24를 유지한다.
- Flutter analyze, 전체 테스트, 웹 릴리스, Android 디버그 빌드가 통과한다.
- 실제 폰 관찰 전에는 신규 아트를 `approved`로 바꾸지 않는다.

## 범위 밖

- 유료 상점, 신규 인앱결제, 장비 뽑기.
- 특수 진화·도전 변형·외형 보상의 실제 해금 시스템.
- 기본 12종 이후의 추가 무기.
- 기본 3명 이후의 추가 캐릭터와 기본 2개 이후의 추가 스테이지.
