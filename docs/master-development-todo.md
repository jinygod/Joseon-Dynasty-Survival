## 표기 규칙

- `[x]`: 검증까지 완료
- `[ ]`: 미완료
- 책임: `Codex`, `사용자`, `공동`
- 우선순위: `P0` 출시 차단, `P1` 1.0 필수, `P2` 품질 향상, `P3` 출시 후
- 선행 작업 ID가 끝나기 전에는 해당 작업을 시작하지 않는다.
- 사용자 작업이 차단되어도 독립적인 Codex 작업은 다음 순서대로 계속한다.

```powershell
.\tool\release_check.ps1
```

Android SDK가 준비된 환경에서는 다음을 실행한다.

```powershell
.\tool\release_check.ps1 -IncludeAndroid
```
