# 일반 적 압박 기준선

`BAL-004`는 신참 포졸(체력 105, 이동 속도 125)과 1레벨 환도(피해 8, 재사용 0.72초)를 공통 기준으로 사용한다. 접촉 피해는 실제 `CombatSystem`의 적별 0.5초 재피격 간격으로 계산한다.

## 조정

첫 1분 학습용 역병 쥐떼의 체력을 10에서 8로 낮췄다. 환도와 부적의 시작 피해가 모두 8이므로 어느 시작 캐릭터든 첫 적을 한 번에 처치할 수 있다. 이후 적의 역할 수치는 유지했다.

## 일반 적 기준선

| 적 | 1레벨 환도 타수 | 연속 공격 처치 시간 | 계속 접촉 시 생존 | 플레이어 대비 속도 |
| --- | ---: | ---: | ---: | ---: |
| 역병 쥐떼 | 1 | 0.00초 | 8.50초 | 44% |
| 산적 | 3 | 1.44초 | 6.50초 | 48% |
| 원혼 | 3 | 1.44초 | 5.00초 | 36% |
| 도깨비 | 5 | 2.88초 | 4.00초 | 29% |

모든 일반 적은 시작 상태에서 3초 이내 처치 가능하고, 단일 적과 계속 겹쳐도 최소 4초 생존하며, 기본 추격 속도는 플레이어의 50% 미만이다. 원혼의 돌진과 쥐떼 분산은 별도 행동 테스트로 검증한다.

## 웨이브 압박

보스 전까지 동시 적 상한은 `24 → 32 → 42 → 54 → 64`, 초당 생성률은 `0.65 → 0.90 → 1.15 → 1.45 → 1.80`으로 계속 증가한다. 270초 보스 등장 후 일반 적 상한은 28, 생성률은 0.45로 내려 보스 패턴을 읽을 공간을 만든다.

이 기준은 단일 적의 불합리한 수치를 막는 자동 안전선이다. 여러 적의 포위, 실제 회피 체감과 억울한 피격은 실기기 플레이테스트에서 별도로 확인한다.
