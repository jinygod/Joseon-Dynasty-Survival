# 전투 피드백 기준선

`BAL-006`은 모바일 화면에서 피격을 읽을 수 있으면서 여러 효과가 조작과 시야를 방해하지 않도록 다음 값을 공통 기준으로 사용한다.

- 플레이어 피격 무적: 0.35초. 서로 다른 적이 같은 순간 겹쳐도 한 번만 피해를 받는다.
- 적별 접촉 재피격: 기존 0.5초 유지. 전역 무적과 함께 단일 적·다중 적 연타를 모두 제한한다.
- 적 누적 넉백 속도: 최대 120. 도깨비의 70% 저항은 상한 적용 전에 유지한다.
- 화면 흔들림: 0.12초, 최대 4px. 보스와 일반 범위 공격 모두 같은 상한을 사용한다.
- 동시 피해 숫자: 40개에서 24개로 축소. 작은 모바일 화면의 겹침과 컴포넌트 폭증을 줄인다.

디버그·테스트용 직접 `takeDamage` 호출은 시각 없이 강제 피해를 줄 수 있고, 실제 접촉·보스 범위 공격은 런 시간을 전달해 무적 판정을 적용한다.
