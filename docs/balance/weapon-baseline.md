# 무기 밸런스 기준선

`BAL-002` 기준선은 코드 수치로 재현 가능한 이론 출력과 실제 런 텔레메트리 관측을 분리한다. 이론 출력은 회귀 탐지용이며, 서로 다른 공격 형태의 최종 우열을 단독으로 판정하지 않는다.

## 재현 방법

```powershell
dart run tool/weapon_balance_report.dart
```

시나리오는 60초 동안 대상이 끊기지 않고 공급되며 대상 체력은 20이다. 공격은 0초에 즉시 시작한다. 환도는 같은 대상에 닿는 베기 수, 각궁은 모든 관통, 부적은 모든 연쇄, 벽력진천뢰는 폭발 하나당 4개 대상 적중을 가정한다. 분당 환산 처치는 총 피해 예산을 대상 체력으로 나눈 값이라 실제 오버킬·이동·명중 실패는 반영하지 않는다.

## 최초 기준선

| 무기 | 레벨 | DPS | 분당 환산 처치 |
| --- | ---: | ---: | ---: |
| 환도 베기 | 1 | 11.20 | 33.0 |
| 환도 베기 | 5 | 69.60 | 208.0 |
| 각궁 사격 | 1 | 6.77 | 20.0 |
| 각궁 사격 | 5 | 126.00 | 378.0 |
| 부적 투척 | 1 | 5.73 | 17.0 |
| 부적 투척 | 5 | 85.00 | 255.0 |
| 벽력진천뢰 | 1 | 22.40 | 67.0 |
| 벽력진천뢰 | 5 | 145.07 | 435.0 |

장승 결계와 신기전 일제사격은 콘텐츠 정의만 있고 레벨 데이터와 런타임 공격 로직이 없어 미구현으로 보고된다. 해당 무기의 숫자는 `CNT-004` 구현 전까지 기준선에 포함하지 않는다.

## 실제 사용률과 관측 성능

`WeaponUsageAggregator`는 저장된 유효 런 전체를 분모로 사용률을 계산한다. 피해·처치 맵에 있거나 무기 선택 기록에 등장하면 해당 런에서 사용한 것으로 센다. 관측 DPS와 분당 처치는 그 무기가 사용된 런의 생존 시간만 분모로 삼는다.

현재 저장소에는 배포 가능한 실제 플레이 표본이 없으므로 최초 사용률 수치는 `측정 불가(0런)`다. 값 0%로 오해하지 않도록 임의 수치를 만들지 않는다. `TEL-006`으로 쌓인 런을 내보낸 뒤 같은 집계기를 사용하고, 최소 내부 20런·외부 10명 기준을 채운 결과는 `BAL-009`에서 이 문서에 추가한다.

## 해석

- 레벨 5의 광역 잠재 출력 차이가 크므로 실제 런의 적중률·오버킬을 포함한 관측 DPS와 함께 판단한다.
- 특정 무기의 사용률과 관측 DPS가 모두 지속적으로 높으면 독점 후보, 사용률과 DPS가 모두 낮으면 상향 후보로 분류한다.
- 이론 수치만으로 즉시 너프하지 않는다. 동일 시드 회귀와 실제 플레이 사망 구간을 함께 확인한다.
