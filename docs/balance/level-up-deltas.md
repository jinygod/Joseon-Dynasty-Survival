# 레벨업 변화량 표시 기준

`BAL-007` 이후 레벨업 카드는 설명 문구가 아니라 실제 생산 수치에서 계산한 현재값과 다음값을 표시한다.

- 무기: 해당 레벨에서 실제로 바뀌는 피해, 재사용 시간, 범위, 공격 수, 관통, 연쇄, 넉백만 `현재 → 다음`으로 표시한다.
- 신규 무기: `신규`와 1레벨 효과를 표시한다.
- 증강: 게임에서 사용하는 누적 배율을 기준으로 피해·이동·공격 속도·치명타·크기·획득 반경·최대 체력을 `현재 → 다음`으로 표시한다.
- 즉시 회복형은 누적 수치가 아니므로 실제 회복량을 표시한다.

레벨 데이터나 런타임 효과가 아직 없는 장승 결계, 신기전 일제사격, 도깨비불, 최후의 저항, 의식 단축은 카드 후보에서 제외한다. 빈 설명이나 선택 후 무효 효과를 제공하지 않으며, `CNT-004`·`CNT-006`에서 실제 로직과 레벨 데이터가 추가될 때 지원 목록에 편입한다.

예시:

- 환도 2→3: `피해 10 → 12 · 재사용 0.72초 → 0.60초 · 넉백 50 → 55`
- 무예 단련 4→5: `무기 피해 +48% → +60%`
- 빠른 장전 3→4: `공격 속도 +30% → +40%`
