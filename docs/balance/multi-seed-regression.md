# 다중 시드 5분 회귀 기준

`BAL-008`은 기존 시드 7 하나의 보스 경계 검사에 더해 시드 0~19의 전체 5분 웨이브를 0.25초 간격으로 재생한다.

## 시뮬레이션 모델

- 실제 `WaveDirector`, 웨이브 데이터, 적 체력을 그대로 사용한다.
- 일반 적의 활성 수명을 `18초 + 체력/5`, 엘리트는 그 1.5배로 모델링해 처치와 퇴장을 재현한다.
- 이 모델은 플레이어 승률을 예측하지 않는다. 생성 예산, 적 풀, 활성 상한, 엘리트 확률, 보스 요청의 결정론적 회귀를 검증한다.

## 모든 시드의 필수 불변식

- 300초 동안 보스 요청 정확히 1회.
- 프레임당 생성 8개 이하, 남은 활성 용량을 넘는 신규 생성 0회.
- 270초 상한이 64→28로 바뀔 때 기존 적은 강제 삭제하지 않으며, 잔존 초과는 10초(0.25초 표본 40개) 이내에 해소.
- 각 시각의 웨이브 적 풀 밖 생성 0회.
- 학습·빌드·압박·보스 구간 모두 일반 적 생성 기록 존재.
- 압박 구간 전체 표본에서 엘리트 생성 존재.
- 동일 시드는 동일 JSON과 지문을 만들고, 20개 시드는 10개보다 많은 서로 다른 지문을 만든다.

향후 웨이브·적 체력·엘리트 확률을 변경하면 지표가 바뀔 수 있지만 위 불변식은 유지되어야 한다. 실제 전투 결과와 메모리 누수는 별도 게임 통합·성능 테스트에서 검증한다.
