# 보스 밸런스 기준선

`BAL-005`는 270초에 등장하는 타락한 관군 대장이 기본 300초 런 안에서 읽을 수 있는 패턴과 실제 광폭화를 제공하도록 조정한다.

- 체력: 700 → 900. 후반 빌드의 순간 삭제를 줄이되 30초 결전 목표는 유지한다.
- 기본 패턴 주기: 접근 1.0초 + 돌진 경고 0.75초 + 원뿔 단계 1.25초 = 3.0초.
- 돌진 경고: 0.5 → 0.75초. 원뿔 공격 경고는 0.6초 유지.
- 소환: 체력 40% 이하에서 한 번만 실행.
- 광폭화: 등장 60초 후 → 25초 후. 기본 5분 런에서도 마지막 5초 동안 발동한다.
- 광폭 배율: 이동·패턴 1.35 → 1.25. 발동은 빨라졌지만 회피 불가능한 급가속을 완화한다.

보스 체력의 최종값은 실제 빌드별 관측 DPS가 쌓이는 `BAL-009`에서 다시 확인한다. 자동 테스트는 체력, 최소 경고 시간, 기본 주기, 광폭화 시점과 배율을 회귀 안전선으로 사용한다.
