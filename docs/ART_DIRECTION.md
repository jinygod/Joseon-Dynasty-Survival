# 조선 민속 판타지 아트 디렉션

## 제품 목표

이 프로젝트의 시각 목표는 기능 확인용 프로토타입이 아니라 실제 출시 가능한 가로형 모바일 뱀서라이크다. 모든 화면과 전투 오브젝트는 같은 세계, 같은 광원, 같은 외곽선 규칙을 공유해야 한다. 작은 휴대폰에서도 플레이어, 적, 공격, 위험 예고가 배경보다 먼저 읽혀야 한다.

## 핵심 인상

- 조선 후기의 생활 재료와 민속 신앙을 바탕으로 한 따뜻하고 기묘한 판타지
- 깔끔하고 아기자기하지만 유아적이지 않은 모바일 게임 캐릭터
- 크고 명확한 덩어리, 절제된 내부 디테일, 한눈에 구별되는 실루엣
- 먹빛 남색, 종이 아이보리, 단청 청록을 기본으로 하고 금색과 주홍을 강조색으로 사용
- 배경은 저채도·저대비, 게임플레이 오브젝트는 높은 명도 대비와 선명한 외곽선 사용

## 형태 언어

### 플레이어

- 머리, 모자, 상의, 주 무기의 네 덩어리가 축소 상태에서도 분리되어야 한다.
- 플레이어 외곽선은 적보다 밝은 크림색 림라이트 또는 청록 보조광을 가진다.
- 이동 방향과 공격 방향은 얼굴, 어깨, 무기 실루엣으로 읽혀야 한다.
- 캐릭터 본체에 UI 기호나 단색 원을 덧씌워 정체성을 대신하지 않는다.

### 몬스터

- 종별로 키, 폭, 머리 장식, 이동 자세 중 최소 두 항목이 달라야 한다.
- 일반 적은 플레이어보다 낮은 채도, 엘리트와 보스는 별도의 외곽선·장식·크기 차이를 사용한다.
- 쥐 떼는 하나의 검은 얼룩이 아니라 여러 몸체와 꼬리 방향이 읽히는 군집 실루엣으로 표현한다.
- 피격 가능 영역은 투명 여백이 아닌 실제 몸통 덩어리를 기준으로 한다.

### 무기와 투사체

- 투사체는 이동 방향을 알 수 있는 앞·뒤 형태를 가진다.
- 실제 무기 이미지가 화면에 존재해야 하며 원, 사각형, 타원 fallback을 릴리스에서 허용하지 않는다.
- 빠른 투사체는 작은 정지 이미지보다 선명한 몸체와 짧은 잔상을 함께 사용한다.
- 잔상은 판정 범위를 과장하지 않으며, 실제 물체와 구분되는 낮은 불투명도를 사용한다.

### 전투 효과

- 공격 궤적은 밝은 중심, 색상 띠, 어두운 외곽의 3단 명도 구조를 기본으로 한다.
- 피격 효과는 공격 효과보다 작고 짧으며 실제 접촉점에서 발생한다.
- 공격 준비, 활성 타격, 회복이 색과 밝기 변화로 구분되어야 한다.
- 지속 장판과 위험 예고는 바닥 문양 PNG를 사용하고 단색 원형 채움으로 완성 처리하지 않는다.
- 흰색 섬광은 1~2프레임의 강조로 제한하며 화면 전체를 씻어내지 않는다.

## 광원과 외곽선

- 기본 광원은 화면 좌상단의 차가운 달빛이다.
- 캐릭터와 적의 하단·우측에는 따뜻한 어두운 그림자를 둔다.
- 게임플레이 스프라이트 외곽선은 최종 표시 크기 기준 1.5~2.5px로 보이게 한다.
- VFX는 완전한 검은 외곽선 대신 짙은 남색 또는 공격 속성색의 어두운 톤을 사용한다.
- 서로 다른 생성 배치의 에셋도 광원 방향과 외곽선 굵기가 같아야 한다.

## 색상 우선순위

| 역할 | 기준색 | 용도 |
|---|---:|---|
| 먹빛 남색 | `#111B2B` | 패널, 윤곽, 깊은 그림자 |
| 종이 아이보리 | `#F4E7C5` | 텍스트, 테두리, 밝은 면 |
| 단청 청록 | `#2E7D73` | 플레이어 보조광, 선택 상태 |
| 금색 | `#E7B84B` | 핵심 행동, 보상, 숙련 강조 |
| 주홍 | `#C94A3A` | 피해, 위험, 경고 |
| 달빛 청색 | `#8FC9E8` | 영적 효과, 얼음, 밤 광원 |

속성색은 정체성을 보조하지만 형태를 대신하지 않는다. 적록 색각 이상에서도 아이콘, 패턴, 외곽선으로 상태를 구별할 수 있어야 한다.

## 배경과 전투 가독성

- 중앙 전투 공간은 낮은 대비의 바닥 타일과 희박한 데칼만 사용한다.
- 높은 대비의 건축물, 나무, 담장, 장식은 월드 가장자리와 랜드마크에 집중한다.
- 플레이어 주변 160월드 단위 안에는 캐릭터와 유사한 명도·채도의 큰 데칼을 배치하지 않는다.
- 배경 그림자와 캐릭터 그림자는 방향을 통일하되 캐릭터 그림자는 더 선명하게 한다.
- 타일 반복은 최소 네 가지 저대비 변형과 별도 희소 데칼로 분산한다.

## 해상도와 축소 검증

- 전투 캐릭터 원본은 128px 셀을 기본으로 하며 실제 표시 크기에서 먼저 검토한다.
- 투사체와 작은 아이콘은 64px 이상 원본을 사용하고 24px 표시에서도 실루엣을 확인한다.
- VFX 시트는 프레임별 128px 셀을 기본으로 한다.
- UI 일러스트는 실제 카드 종횡비에 맞게 제작하며 정사각형 이미지를 억지로 자르지 않는다.
- 모든 에셋은 100%, 50%, 실제 기기 표시 크기의 세 단계에서 검토한다.

## 금지 항목

- 원, 사각형, 타원, 단색 경로를 최종 캐릭터·몬스터·무기·전투 효과로 사용
- 기존 에셋을 다른 캐릭터나 몬스터의 이름만 바꿔 재사용
- 투명 여백이 과도한 스프라이트
- 배경보다 낮은 명도 대비의 플레이어·적·투사체
- 서로 다른 광원 방향, 외곽선 굵기, 픽셀 밀도를 가진 에셋 혼용
- 임시 에셋, `ASSET MISSING`, generic icon을 릴리스 완료 상태로 인정

## 완료 판정

에셋은 파일이 존재하는 것만으로 완료되지 않는다. 실제 전투 또는 실제 화면에 적용하고 다음 조건을 모두 만족해야 한다.

1. 목표 모바일 해상도에서 실루엣과 기능이 즉시 읽힌다.
2. 배경과 겹쳐도 외곽선이 무너지지 않는다.
3. 시각 범위와 판정 디버그 오버레이가 일치한다.
4. 실행 스크린샷을 전후 비교하고 아트 디렉션 위반이 없다.
5. 에셋 출처, 생성 프롬프트, 후처리, SHA-256이 기록된다.
