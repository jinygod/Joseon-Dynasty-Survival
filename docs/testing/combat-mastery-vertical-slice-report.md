# 전투 마스터리 수직 슬라이스 보고서

이 문서는 스키마 1·2 원본 텔레메트리의 자동 집계와 실제 플레이 수동 검증을
분리한다. 원본 CSV/JSON은 보존하며, 집계값만으로 시각·조작 경험을 판정하지 않는다.

## 자동화 증거

`TelemetryExportService.aggregate`는 다음 형식화된 집계값을 제공한다.

- 무기별 제안·선택 횟수와 선택률
- 무기별 피해 비중, 레벨 도달 평균 시각, 최초 마스터 평균 시각과 마스터 후
  10초 평균 처치 수
- 시너지별 최초 발동 평균 시각, 피해 비중과 전체 시너지 피해 비중
- 적 역할별 플레이어 피해량과 사망 원인 횟수
- 평균·최대 적 밀도, 후반 평균·최저 FPS
- 마스터 런과 비마스터 런의 승률, 반복 런 비율

0인 분모는 0으로 보고하며 스키마 1의 비어 있는 전투 지표는 누락 데이터로
안전하게 처리한다. 원본 내보내기 경로인 단일 런 JSON 복사와 전체 JSON 공유는
변경하지 않는다.

자동 검증 명령:

```powershell
flutter test test/game/telemetry_export_service_test.dart test/game/run_telemetry_test.dart
```
