Joseon Dynasty Survival Manual QA Test Cases
Last updated: 2026-07-14
Branch: codex/pixel-survivor-mvp

Purpose
이 문서는 플레이어가 대충 한 판 해보는 것이 아니라, 현재 구현된 MVP 기능을 하나씩 확인하기 위한 수동 테스트 케이스다.
자동 단위 테스트로 이미 커버되는 항목은 "자동 매핑"에 테스트 파일을 적었다.

Current Build Notes
- 현재 그래픽은 최종 도트 이미지가 아니라 Flame 기본 도형/임시 UI 기반이다.
- 현재 기본 플레이어는 Rookie Constable 1명이다.
- 현재 시작 무기는 환도 베기이며, 각궁 사격은 시작 해금 상태라 레벨업 선택 후보로 나온다.
- 첫 스테이지의 핵심 무기는 환도 베기, 각궁 사격, 부적 투척, 벽력진천뢰 4종이며 각각 5레벨까지 성장한다.
- 첫 레벨업 요구 XP는 5이며, 이후 레벨마다 요구량이 1씩 증가한다.
- 웨이브는 0, 60, 120, 180, 240, 270초에 전환되고 구간별 스폰 속도, 무리 크기, 정예 확률, 생존 상한이 증가한다.
- 270초에 타락한 별장 보스가 등장한다. 330초까지 살아 있으면 광폭화한다.
- 승리 조건은 보스 처치이며 플레이어 사망과 같은 프레임이면 보스 처치를 먼저 판정한다.
- 장기 해금 목표: 180초 생존 Talisman Throw, 누적 300킬 Thunder Crash Bomb, 런 레벨 10 Jangseung Ward/Rapid Reload, Fallen General 처치 Exorcist Dosa, 300초 생존 Goblin Fire, 무기 3개 해금 Powder Mastery, 누적 500킬 Singijeon Volley.
