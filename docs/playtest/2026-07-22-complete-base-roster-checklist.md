# 모바일 수직 슬라이스 플레이 체크리스트

## 시작 전

- 캐릭터 3종과 맵 2종에 잠금 표시가 없고 바로 선택되는지 확인한다.
- 새 런에서 기본 무기 12종이 레벨업 후보로 등장할 수 있는지 확인한다.
- 한 런에서 새 무기는 최대 6종까지만 획득되고, 이후에는 보유 무기 강화가 제시되는지 확인한다.

## 대표 아트

- 기본 캐릭터가 큰 성인형 임시 이미지가 아니라 귀여운 3~4등신 캐릭터로 보이는지 확인한다.
- 캐릭터 얼굴·갓·붉은 철릭·손의 무기가 작은 폰 화면에서도 구분되는지 확인한다.
- 쥐 떼, 원혼, 삿갓 망령, 도깨비가 실루엣만으로 서로 구분되는지 확인한다.
- 이동·공격·피격·사망 동작에서 화질이 뭉개지거나 프레임 칸이 섞여 보이지 않는지 확인한다.
- 주황색 사각형이나 정체불명의 대체 도형이 대표 적 대신 보이지 않는지 확인한다.

## 모바일 조작과 UI

- 캐릭터가 좌우로 방향을 바꿀 때 중간에 납작해지거나 판처럼 회전하지 않고 즉시 2D 반전되는지 확인한다.
- 캐릭터 발밑의 작은 체력바가 항상 수평이며 안전·주의·위험 구간의 색상 변화가 보이는지 확인한다.
- 입력이 없을 때 조이스틱이 화면 하단 중앙에 보이는지 확인한다.
- 화면 왼쪽과 오른쪽의 서로 다른 빈 곳에서 각각 드래그를 시작했을 때 최초 접촉 지점이 새 조이스틱 중심이 되는지 확인한다.
- 손가락을 떼면 이동이 즉시 멈추고 조이스틱 안내가 하단 중앙으로 돌아오는지 확인한다.
- 일시정지와 성장 선택 카드를 누를 때 조이스틱이 입력을 가로채지 않는지 확인한다.
- 세로 로비에서 맵·캐릭터·최고 기록·출진 버튼이 중앙 무대에 보이고 하단 메뉴 4개가 모두 접근 가능한지 확인한다.
- 세로 성장 선택 화면에서 세 카드의 이름, 레벨 변화, 효과 설명이 말줄임 없이 전부 보이는지 확인한다.

## 무기 성장

- 각궁이 5레벨에서 끝나지 않고 6레벨 `관월추성`까지 올라가는지 확인한다.
- 각궁 6레벨이 가장 강한 적을 향한 큰 선두 화살과 후속 화살 2발로 보이며 폭발 무기처럼 보이지 않는지 확인한다.
- 환도·부적·폭탄·장승·신기전·서리·부채의 6레벨이 5레벨보다 공격 수와 화면 점유가 분명히 커지는지 확인한다.
- 조총·화포는 굵은 관통탄과 끝 지점 폭발, 무당 방울은 동심 파동, 도깨비 쇠사슬은 6방향 끌어모으기, 매 부리기는 5열 급강하로 구분되는지 확인한다.
- 서로 다른 무기의 탄환·궤적·범위가 각기 다른 대표색으로 보이는지 확인한다.

## 전투 가독성과 뽕맛

- 후반 일반 적 무리가 마스터 공격에 대량 처치되지만 엘리트·보스는 즉시 삭제되지 않는지 확인한다.
- 돌진형 예고선, 원거리 투사체, 방어형 정면 방패가 플레이어 공격 이펙트 뒤에서도 보이는지 확인한다.
- 강한 공격의 타격 정지·화면 흔들림이 짧고, 연속 발동해도 화면이 계속 흔들리지 않는지 확인한다.
- 후반에 조작 지연이나 심한 프레임 저하가 없는지 확인한다.
- 게임 종료 후 같은 캐릭터 또는 다른 캐릭터로 두 번째 런을 정상 시작할 수 있는지 확인한다.

## 판정

- 재미 평가는 자동 로그만으로 확정하지 않는다.
- `무기 6레벨 전후의 화면 변화`, `10초간 처치 수`, `회피 가능한 적 예고`, `다시 한 판 의향`을 직접 기록한다.
- 대표 아틀라스는 외부 폰 테스트에서 승인되기 전까지 `temporary` 상태를 유지한다.
