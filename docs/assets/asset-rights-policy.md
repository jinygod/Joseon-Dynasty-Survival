# 시각 자산 권리·반입 정책

결정일: 2026-07-15  
적용 범위: 게임에 포함되는 스프라이트, 아이콘, 이펙트, 배경, UI 이미지와 그 원본

## 결정

1. 기본 제작 경로는 **직접 제작 또는 프로젝트 전용 AI 생성 후 사람의 수정·검수**로 한다.
2. 구매·외주 자산은 상업용 게임 배포, 수정, 전 세계·기간 제한 없는 사용이 계약이나 라이선스에 명시된 경우에만 허용한다.
3. 무료·오픈 자산은 정확한 라이선스 원문과 취득일을 보관하고, 표시 의무·동일조건변경허락 의무가 출시 방식과 충돌하지 않을 때만 허용한다.
4. 출처 불명, 검색 이미지, 다른 게임의 추출물, 팬아트, 상표·유명 캐릭터·실존 인물의 식별 가능한 외형 모방은 금지한다.
5. 권리 증빙이 한 칸이라도 비어 있으면 임시 개발 폴더에서만 사용할 수 있고 릴리스 자산 목록에는 등록하지 않는다.

이 정책은 법률 자문을 대신하지 않는다. 권리 주장이 들어오거나 라이선스가 불명확하면 해당 자산을 즉시 격리하고 대체한다.

## 경로별 필수 증빙

| 경로 | 반입에 필요한 증빙 |
|---|---|
| 직접 제작 | 제작자, 제작일, 편집 가능한 원본 경로, 프로젝트에 대한 권리 귀속 확인 |
| AI 생성 | 제공자·제품·모델, 생성일, 전체 프롬프트, 입력 이미지와 그 권리, 당시 약관 URL·확인일, 원본 출력, 사람의 수정 내역 |
| 구매 | 판매 페이지·주문/영수증, 라이선스 원문 사본, 구매일, 허용 플랫폼·수정·재배포 조건 |
| 외주 | 서면 계약, 납품 목록, 대금 증빙, 상업 사용·수정·2차 저작물·전 세계 배포에 필요한 권리 귀속 또는 독점 라이선스 |
| 무료·오픈 | 제작자, 원문 URL, 라이선스 이름·버전·원문 사본, 표시 문구, 변경 여부 |

OpenAI 생성 자산을 사용할 때는 현재 이용약관이 입력 권리를 사용자 책임으로 두고, OpenAI와 사용자 사이에서는 허용되는 법률 범위에서 출력 소유권을 사용자에게 귀속시키지만 출력의 고유성을 보장하지 않는다는 점을 전제로 한다. 따라서 출력 소유 주장만으로 반입하지 않고 유사성·상표·실존 인물 검수를 별도로 수행한다. 기준 자료: [OpenAI Terms of Use](https://openai.com/policies/terms-of-use/), [OpenAI Service Terms](https://openai.com/policies/service-terms/) (확인일 2026-07-15).

## AI 생성 금지 입력·검수

- 특정 생존 게임, 화가, 스튜디오, 캐릭터의 이름을 스타일 지시로 사용하지 않는다.
- 저작권이 불명확한 이미지를 참조 이미지로 업로드하지 않는다.
- 실존 인물의 얼굴·체형·음성 또는 유명 상표를 재현하도록 지시하지 않는다.
- 결과물은 역이미지 검색, 육안 유사성 검토, 상표·문자·워터마크 확인 후 사용한다.
- 생성 결과에 우연히 나타난 서명, 워터마크, 로고, 읽을 수 있는 문자는 삭제가 아니라 해당 결과 폐기를 원칙으로 한다.

## 반입 절차

1. 원본을 `source_assets/` 외부 보관소에 읽기 전용으로 보존한다. 게임 패키지에는 최적화 사본만 넣는다.
2. `docs/assets/asset-rights-ledger.csv`에 한 자산당 한 행을 만들고 모든 필수 칸을 채운다.
3. 아트 스타일·해상도·투명 배경 검수를 통과시킨다.
4. 제3자 유사성, 상표, 실존 인물, 금지 콘텐츠를 사람이 검수한다.
5. 승인 상태가 `approved`인 자산만 `AssetCatalog`와 `pubspec.yaml`에 등록한다.
6. 원본·프롬프트·약관·영수증 파일의 SHA-256을 장부에 남겨 사후 변경을 식별한다.

## 상태와 교체 규칙

- `draft`: 제작 중이며 앱 패키지 반입 금지.
- `review`: 증빙과 시각 검수 중이며 내부 빌드만 허용.
- `approved`: 모든 필수 증빙과 검수를 통과해 릴리스 가능.
- `blocked`: 권리 또는 유사성 문제가 있어 사용 금지.
- `retired`: 이전 승인 자산이지만 새 빌드에서 제거됨.

약관 변경만으로 기존 자산의 권리가 자동으로 확정되거나 소멸한다고 판단하지 않는다. 생성·구매 당시 약관 사본을 기준 증빙으로 보존하고, 출시 전과 분쟁 통지 시 다시 검토한다.

## 출시 게이트

- 릴리스 빌드의 모든 시각 자산이 장부에 존재한다.
- 모든 행이 `approved`이고 필수 증빙 경로와 SHA-256이 존재한다.
- 필요한 크레딧이 게임 내 크레딧 및 스토어 설명과 일치한다.
- 교체 가능한 원본과 담당자가 기록되어 있다.
- 하나라도 실패하면 `VIS-014` 및 최종 라이선스 게이트를 통과시키지 않는다.
