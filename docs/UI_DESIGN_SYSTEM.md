# 조선 민속 판타지 UI 디자인 시스템

## 목표 화면

기본 제품 방향은 가로형 모바일이다. 기준 viewport는 16:9와 19.5:9 landscape이며 짧은 변 360~430dp를 우선 검증한다. 노치, 카메라 홀, 시스템 제스처 영역을 SafeArea로 보존한다. 세로 화면은 개발·접근성 보조 경로일 수 있지만 최종 레이아웃의 기준이 아니다.

## 원칙

- 게임 세계를 가리지 않는 낮고 넓은 정보 구조
- 종이, 목재, 옻칠, 금속 장식을 단순화한 조선풍 표면
- 장식보다 숫자와 행동 우선
- 한 화면에서 하나의 주 행동만 금색으로 강조
- Flutter 기본 Material 표면을 그대로 노출하지 않음
- 아이콘만으로 의미를 강요하지 않고 짧은 한글 레이블 제공

## 색상 토큰

| 토큰 | 값 | 용도 |
|---|---:|---|
| `ink900` | `#0C1422` | 최심부 배경 |
| `ink800` | `#111B2B` | 패널 |
| `ink700` | `#1C2A3B` | 패널 상승면 |
| `paper100` | `#F4E7C5` | 기본 글자, 테두리 |
| `paper300` | `#D8C59B` | 보조 글자 |
| `gold500` | `#E7B84B` | 주 행동, 보상 |
| `teal500` | `#2E7D73` | 선택, 진행 |
| `red500` | `#C94A3A` | 위험, 피해 |
| `moon400` | `#8FC9E8` | 영적 효과, 포커스 |

텍스트 대비는 일반 본문 4.5:1 이상, 큰 글자와 아이콘 3:1 이상을 유지한다.

## 타이포그래피

- 제목: 프로젝트에 포함된 조선풍 제목 글꼴, 22~30sp, 한 줄
- 숫자: 폭이 안정적인 굵은 숫자 스타일, 16~24sp
- 본문: 가독성 중심 한글 글꼴, 14~18sp
- 보조: 12sp 미만을 사용하지 않음
- 공격력, 체력, 속도 등 핵심 수치는 백분율 대신 정수로 표시
- 텍스트 배율 2.0에서도 핵심 행동과 스크롤 접근을 보존

## 표면과 패널

`Card`, `ListTile`, 기본 `AppBar`, 기본 `ActionChip`, 기본 `SwitchListTile`을 최종 게임 UI로 사용하지 않는다.

대신 다음 공용 구성 요소를 사용한다.

- `JoseonScreenFrame`: 배경, SafeArea, 상단 명패
- `JoseonPanel`: 먹빛 반투명 본체, 아이보리 1px 선, 안쪽 금색 모서리
- `JoseonPrimaryButton`: 금색 면, 먹빛 글자, 눌림 깊이
- `JoseonSecondaryButton`: 남색 면, 아이보리 선
- `JoseonNavTab`: 선택 시 청록 매듭 또는 금속 못 장식
- `JoseonToggleRow`: 커스텀 트랙·손잡이와 명시적 상태 텍스트
- `JoseonItemRow`: 썸네일, 제목, 설명, 상태를 독립 배치
- `JoseonLoadingSeal`: 원형 Material spinner 대신 회전하는 인장 PNG

모서리 문양은 장식 면적의 10% 이하로 제한하고 정보 영역을 침범하지 않는다.

## 전투 HUD

- 화면 상단 중앙에 시간, 레벨, 경험치, 처치 수를 한 줄 또는 두 줄로 압축한다.
- 일시정지는 좌상단 SafeArea 안에 44dp 이상 터치 영역으로 둔다.
- 핵심 무기 슬롯은 우상단에 두고 적 경고를 가리지 않는다.
- 패널 배경은 짙은 남색 72~82% 불투명도, 아이보리 얇은 선, 금색 핵심 숫자
- 조이스틱은 입력하지 않을 때 낮은 불투명도이며 입력 중에만 선명해진다.
- HUD와 조이스틱은 viewport 좌표를 사용하고 월드 카메라의 자식이 아니다.

## 로비

- 가로 화면 중앙을 캐릭터와 배경 장면에 할당한다.
- 재화와 계정 상태는 얇은 상단 명패, 주요 탐색은 하단 또는 양측 도크에 배치한다.
- 출전 버튼은 화면의 유일한 큰 금색 행동이다.
- 캐릭터, 도감, 기록, 상점은 서로 다른 Material 아이콘이 아니라 통일된 PNG 아이콘 세트를 사용한다.
- 로딩, 오류, 재시도도 같은 패널과 버튼 체계를 사용한다.

## 도감

- 왼쪽은 분류 탭, 중앙은 항목 목록, 오른쪽은 큰 일러스트와 설명을 사용하는 landscape master-detail 구조를 우선한다.
- 잠긴 항목은 내용 유출 없이 고유 실루엣과 해금 조건을 보여준다.
- atlas 전체를 썸네일로 표시하지 않는다.
- 캐릭터, 무기, 증강마다 목적에 맞는 전용 일러스트 또는 아이콘을 사용한다.
- 새 항목, 잠김, 선택 상태는 색뿐 아니라 배지 형태와 텍스트로 구별한다.

## 상점과 설정

- 상품은 가격, 소유 상태, 구매 행동이 분리된 전용 상품 패널을 사용한다.
- 설정은 custom toggle, slider, segmented control로 구성한다.
- 구매와 계정 삭제처럼 되돌리기 어려운 행동은 주홍색 경고 패널과 2단계 확인을 사용한다.
- 라이선스처럼 긴 텍스트 화면도 기본 Material 카드가 아니라 읽기 전용 종이 패널을 사용한다.

## 입력과 접근성

- 모든 핵심 터치 영역은 최소 44×44dp
- 키보드·게임패드 포커스는 달빛 청색 외곽선과 위치 변화로 표시
- 진동, 화면 흔들림, 피해 숫자, UI 배율 설정을 제공
- 상태는 색상 하나만으로 전달하지 않음
- 화면 낭독 순서는 제목, 핵심 상태, 콘텐츠, 주 행동 순서

## 반응형 기준

- `compactLandscape`: 짧은 변 360~399dp
- `regularLandscape`: 짧은 변 400~479dp
- `largeLandscape`: 짧은 변 480dp 이상

폭만 보고 열 수를 정하지 않고 짧은 변, SafeArea, 텍스트 배율을 함께 사용한다. 공간이 부족하면 장식을 먼저 줄이고 정보와 행동을 유지한다.

## 릴리스 검증

- 16:9, 19.5:9 landscape 실기기 캡처
- 노치와 제스처 영역 침범 없음
- 1.0, 1.3, 2.0 텍스트 배율
- 기본 Material 표면 검색 결과 0건
- `ASSET MISSING`과 generic icon 노출 0건
- 실제 배경 위에서 글자와 터치 상태 가독성 확인
